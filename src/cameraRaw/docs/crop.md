# 裁剪实现

## 交互

- 裁剪是右侧蒙版下方的独立主入口。进入后始终显示完整原图、当前裁剪框、外部暗化和三分网格，退出后显示裁剪结果。
- 拖动框体移动，四角和四边缩放；方向键移动一像素，Shift + 方向键移动十像素。
- 比例支持自定义、原始比例、1:1、4:5、5:7、3:2、16:9，并可交换长宽方向。固定比例按源图像素宽高比换算，Shift 拖动边角可临时切换为自由比例。
- 复位清除裁剪；裁剪与调色共享逐图撤销/恢复和多选同步。

## 渲染

- `engine/crop.ts` 使用归一化源图坐标保存 `CropSettings`，负责比例、边界和输出尺寸计算。
- `RawRenderer` 先在完整源图坐标中完成全局调整与蒙版合成，再通过 `cropFragmentShader` 截取目标区域。蒙版不会因为裁剪发生坐标偏移。
- 预览按裁剪后的宽高比布局；JPEG/DNG 导出使用裁剪后的真实像素尺寸。导出始终不绘制裁剪框。
- 裁剪不属于调色预设，不写入 XMP 预设；当前会话内随图片状态保留。
