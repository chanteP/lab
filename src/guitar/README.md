# 钢弦吉他指板

纯前端 Vue 3 + TypeScript 页面，无音频采样或后端依赖。标准调弦 `E2 A2 D3 G3 B3 E4`，共 20 品，十二平均律换算：`f = 440 × 2^((midi - 69) / 12)`。

## 文件职责

- `App.vue`：页面状态、指板渲染、调式与和弦交互、全部视觉样式。
- `theory/chords.ts`：音名、自然大调、和弦定义、低把位 voicing 搜索。纯函数，无 DOM。
- `audio/GuitarSynth.ts`：Web Audio 物理建模、琴体响应、单音与扫弦。
- `audio/README.md`：音色公式、参数意义与迭代建议。

## 交互约定

开启“显示音阶”后只标记当前自然大调音；未标音的位置仍可点击发声。点击任意音会选中和弦根音并出现和弦工具行；点击和弦后全指板突出该和弦的组成音，其余音半透明，同时按实际 voicing 从低音向高音扫弦。切换调式会将根音同步至新主音。

构建：`yarn build guitar`。不要直接修改 `docs/guitar/`。
