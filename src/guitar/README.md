# 钢弦吉他指板

纯前端 Vue 3 + TypeScript 页面，无音频采样或后端依赖。指板按一弦到六弦自上而下显示；内部统一按六弦到一弦存储。支持标准、Drop D、Open D、Open G 调弦，共 20 品，十二平均律换算：`f = 440 × 2^((midi - 69) / 12)`。

## 文件职责

- `App.vue`：页面状态、指板渲染、调式与和弦交互、全部视觉样式。
- `theory/chords.ts`：音名、自然大调、调弦定义、和弦定义、voicing 搜索及实际按法识别。纯函数，无 DOM。
- `theory/noteColors.ts`：全局固定音名色表。
- 键盘演奏：数字 1–7 为当前调顺阶和弦；A–' 为白键（F=C4），Q–] 为黑键。
- `audio/GuitarSynth.ts`：Web Audio 物理建模、琴体响应、单音与扫弦。
- `audio/AudioVisualizer.vue`：全屏 Canvas，以 60fps 上限绘制真实音频输出波形。
- `arrangement/`：谱子多拍点和弦编排、逐拍歌词、节奏型、四品按法编辑/识别、IndexedDB 谱子库和 PNG 导出；详见其目录文档。
- `audio/README.md`：音色公式、参数意义与迭代建议。

## 交互约定

开启“显示音阶”后只标记当前自然大调音；未标音的位置仍可点击发声。点击任意音会选中和弦根音并出现和弦工具行；点击和弦后全指板突出该和弦的组成音，其余音半透明，同时展示音程公式（如 1 · 3 · 5）、组成音（如 C · E · G）和指法，并将实际 voicing 合成为一段音频后扫弦。C9 按需求采用 1 · 3 · 5 · 9 的简化九和弦定义。切换调式会将根音同步至新主音。

构建：`yarn build guitar`。不要直接修改 `docs/guitar/`。
