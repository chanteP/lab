# 谱子编排模块

## 组件与文件

- `Arrangement.vue`：连续六线谱、谱子库、节拍/BPM、小节拖放、节奏型、走带播放、自动保存和 PNG 导出。
- `ChordEditor.vue`：四品六弦按法浮窗。每根弦可设置一个品位、空弦 `0` 或不按 `null`；所有品位显示固定色音名，当前和弦音高亮，名称随实际发声实时识别。
- `patterns.ts`：按节拍划分的拨弦/扫弦节奏型。每一步记录弦号、扫弦方向与闷音状态。
- `store.ts`：IndexedDB 封装，数据库 `acoustic-guitar-lab`，对象仓库 `arrangements`。
- `types.ts`：谱子、和弦、小节与节奏型的持久化类型。

## 数据与交互

默认四个空小节，网格每行四个，可继续追加。和弦按钮使用 `application/x-guitar-chord` MIME 拖入；触屏也可先点击和弦，再点击空小节。每个小节保存多个 `MeasureChord { beat, chord }` 拍点和弦、逐拍歌词、备注与节奏型；每段和弦保存实际调弦和按法 MIDI，不依赖之后切换的指板调弦。旧版单 `chord` / `lyric` 数据在 `normalizeSong()` 中自动迁移。

`guitar:last-rhythm-pattern` 记录最近节奏型，默认 `53231323`。切换节拍时，不匹配的小节会切换到该拍号的默认型；匹配当前拍号的最近选择优先。

拖过小节时按横向位置计算拍点并显示插入预览，同拍再次拖入会替换；拖到末尾添加区会自动创建小节，即使没有小节也可直接拖入。点击 `＋` 可使用当前和弦填充下一个空闲拍。

谱名后的“本谱和弦”汇总所有用过的按法，自动去重并多行排列，可拖回任意小节且保留自定义按法/转位。桌面每行八个小节，默认不显示热区 border，仅保留谱面小节线，悬停才显示编辑热区。

编辑采用 350ms 防抖自动保存，`guitar:current-arrangement` 记录最近打开的谱子 ID。写入前通过 JSON 深拷贝去除 Vue Proxy。删除有二次确认。

## 播放

播放按每小节八分音符网格计算时值，BPM 对应四分音符。和弦段的结束由下一拍点或小节末尾决定，每段从节奏型第 0 步截取对应长度；和弦前的空拍保持静默。拨弦型逐弦调用 `pluck()`，扫弦型调用单 Buffer 的 `strum()`。扫弦通过 `step.strings` 区分下三弦 `[4,5,6]`、上三弦 `[1,2,3]` 和全弦；拍弦步进调用无音高的 `slap()`；空小节保留静默时值。全部音符通过 Web Audio 时间提前调度，UI 进度与音频时钟共用时间锚点。

暂停记录秒级位置并停止未发声的 source，续播仅重新调度之后的音符；停止清零位置。`transportVersion` 使慢速渲染期间的暂停/停止能够取消后续调度。修改拍号、BPM 或谱面会停止旧播放。播放高亮仅作用于小节与当前步进，不改变热区。

## 导出

PNG 使用按需加载的 `html2canvas`，以 2 倍像素导出 `.sheet-paper`，导出时隐藏添加/删除按钮。采用 Blob URL 并挂载临时下载链接，兼容浏览器下载行为。

## 扩展节奏型

在 `RHYTHM_PATTERNS` 中使用 `pluck()` 或 `strum()` 添加即可。弦号遵循演奏习惯：1 弦为高音 E，6 弦为低音 E。`slap: true` 表示拍弦，谱面以 ×/✕ 表达，不与扫弦共用音效。`steps.length` 决定六线谱列数，应匹配拍号所需八分音符网格。
