# 音名、和弦与颜色

- `chords.ts` 负责十二平均律、调弦、音阶、voicing 与实际按法识别。
- `noteColors.ts` 是全局唯一音名色表，按 pitch class 固定色相；C 始终为鼠尾草绿，跨八度不变。UI 通过 `--note-color` 使用，不允许为同一个音另设色相。

`identifyChord(frets, strings)` 从实际发声识别大三、小三、sus2/sus4、五和弦、增减、六/七/九类常见和弦。最低声部不是根音时生成 slash chord，例如 `G/D`。吉他按法允许省略五音，但根音、三音、七音等决定性音不可缺；未收录的扩展音使用 `…`，不冒充已知三和弦。

键盘：数字 1–7 使用自然大调顺阶和弦 `I IIm IIIm IV V VIm VII°`；字母键使用固定 MIDI，F=C4，和当前调式无关。黑键按 QWERTY 物理间隔与钢琴黑白键共同映射（F/G 键之间的 T=C#4），无黑键的位置留空，不做连续音高填充。输入控件或按法编辑器打开时，App 的全局键盘监听不会响应。
