# 钢弦音色模块

`GuitarSynth.ts` 是唯一发声入口，不依赖 Vue。UI 只传 MIDI 音高、弦序号与力度；和弦音高计算位于 `theory/chords.ts`。

## 音色理论

核心是 **扩展 Karplus–Strong 弦振动模型**：拨弦产生宽频激励，在约一个基频周期的延迟线中循环；每轮高频损失略多，因此起音明亮、余音逐渐变暖。当前实现包括：

- 分数延迟线性插值：避免整数延迟导致音高误差。
- 频率相关阻尼：高把位/高音弦余音更短，低弦保留更多铜缠绕弦的明亮感。
- 梳状着色噪声与极短拨片瞬态：模拟拨片触弦，而非振荡器式纯音。
- 轻量琴体冲击及双声道卷积脉冲：补充面板的低频共振和空间感。
- 力度、弦序声像、动态压缩：让单音与扫弦保持接近真实吉他的动态。

所有采样由本机实时生成并缓存，无网络音频资源。`resume()` 必须由用户手势触发，符合浏览器自动播放策略。

## 调参顺序

1. **延音**：`decayTime`，过大像电吉他，过小像闷音。
2. **明暗**：`damping`，越大高频衰减越快；建议先调它再调激励。
3. **拨片硬度**：`renderString` 中 `pickTransient` 和 comb 的 `0.55`。
4. **琴体**：`createBodyImpulse` 的 196/410 Hz 模态、衰减速度及 `bodyGain`。
5. **输出**：`dry.gain`、`bodyGain.gain` 与 compressor，最后才调总音量。

若后续升级为更真实的模型，可在保持 `pluck()` API 不变的情况下加入双向延迟线（弦长两侧反射）、按弦材质区分激励、品位噪声和更精细的测量琴体 IR。和弦扫弦间隔在 `strum()` 中，默认每弦 24ms。
