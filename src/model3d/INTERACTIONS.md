# Builder 3D 交互与数据约定

本文档记录当前画布、实体树和视图辅助交互。新增工具时应同步更新本文和相关代码分区注释。

当前迭代在用户明确宣布“正式完工”前不保证旧项目数据兼容，不保留迁移或旧功能回退入口。

## 全局

- 页面内禁用浏览器原生右键菜单；实体树与画布分别使用自定义上下文菜单。
- 禁用 Ctrl / Command + 滚轮、触控板手势和键盘快捷键造成的浏览器页面缩放。普通滚轮仍用于 Three.js 相机缩放。
- 空白新项目不自动创建任何实体。
- 草图拖动中撤销/重做会立即取消视口手势和草稿并消费剩余 pointerup，删除的预览不需要 blur 即消失，也不会在松手后重建。
- 所有数值输入最多展示 4 位小数。测量和比例尺是辅助显示，使用最多 2 位小数。
- 右上角单位下拉切换全局 mm/cm/m，所有尺寸输入、测量和比例尺同步更新。
- 3D 工具栏上下分组之间的空档可直接操作画布。搜索、插入、构造平面与工具使用左侧关闭式弹层；插入可选择立方体、圆柱体、球体、圆锥体和圆环，不包含项目导入。

## 实体树

实现：`EntityTree.vue`、`App.vue` 中的 `treeNodes`、`reparentNodes` 和节点菜单方法。

- 文件夹和实体共享同一套 `id / parentId` 父节点数据。实体也可以包含子节点，文件夹不是唯一容器。
- Items 不显示 Sketch 条目；草图仍作为独立数据保存，并通过 History 或画布轮廓重新进入编辑。
- 单击选择，Ctrl / Command / Shift + 单击多选。可见性按钮只作用于实体。
- 节点可单个或多个拖到另一个节点下；拖入空白树区域会移动到根节点。
- 拖入自身或自己的后代会被拒绝，避免循环树。
- 文件夹和实体的右键菜单均提供删除；多选时增加批量重命名，回填首项名称，确认后按选择顺序生成“名称 1、名称 2…”。草图与 3D 均显示文件夹创建按钮，无选择直接创建，有同父级选择时创建并归组；草图文件夹归属当前平面。
- 平面同样支持右键删除，以及选中后的 Delete / Backspace。删除平面会同时删除其草图；存在 Extrude 引用时先阻止并提示依赖。
- 删除文件夹不会删除其中的模型；其子节点会移到根节点。删除实体会同时检查布尔引用。
- 删除节点时仅从当前多选中移除被删除的 id；正在编辑的草图被删除时同步清空其操作点和编辑状态，不误清除其他选择。
- 实体始终使用 cube 图标，文件夹始终使用 folder 图标，不随模型类型变化。
- 文件夹创建按钮只显示文件夹与加号图标；子节点使用树状竖线和横向分支表达 parent 关系。

## 平面与草图

实现：`SketchPlane`、`Viewport.sketchPoint / sketchWorld / updateSketch`、`geometry.ts` 的平面重建逻辑。

- 新草图必须关联显式平面。可通过工具栏添加 XZ、XY 或 YZ 坐标平面，并输入法向偏移。
- 草图点保存为平面局部 `(u, v)`，不是世界坐标，也不是渲染网格顶点。
- 视口拾取时将射线与平面的世界交点转换成 `(u, v)`；预览和拉伸重建时再转换回世界坐标。
- 单击添加点，拖动顶点调整位置，选中顶点后输入局部坐标可精准编辑，厚度可随时输入。
- 选中已有拉伸实体后进入草图工具，可继续编辑原轮廓。

## 选择与相机

- 选择是默认工具。普通单击/双击或实体树选择保持选择，不再隐式切到移动；已显式激活的移动、旋转、缩放在更换选择时继续保留。工具启动、预览或提交失败统一恢复选择。
- 抓手工具（H）的左键拖动与按住 Space 拖动一致，仅平移相机；该工具屏蔽实体单击、双击、框选和悬停拾取，V 或 Esc 返回选择。临时 Space 平移松开后若抓手仍激活，继续保持平移。

实现：`Viewport.onPointerDown`、 `OrientationGizmo.ts`。

- 左键单击选择 face / edge，双击实体选择完整 Body，Shift + 单击累加选择。3D 草图轮廓单击只选择命中的独立面，Ctrl/Command + 单击累加面，不进入边/角选择，也不默认选整个形状；无封闭面的开放线不可在 3D 中选择。草图仍不可通过双击、右键或 Delete 编辑/删除，需要编辑时从 History 显式回改。图片继续整体选择。变换工具激活时，单击实体仍可重新选择几何；只有 gizmo、直接编辑手柄和显式工具消费拖动。
- 实体面/边/角和草图面的 active 必须跟随当前操作实时更新：Translate/Rotate/Scale 每帧跟随实体矩阵，粗箭头推拉和数值输入在几何重建后立即重绑当前面，不等待 blur 或 pointerup。草图编辑模式的 active 面按最新轮廓同步重建。
- 3D 工具栏顶部提供选择和抓手，之后按构造平面、草图、插入、导入排列；导入直接选择 STL/OBJ/GLB 文件并加入当前项目，项目 YAML 导入仍位于侧栏项目菜单。
- 点击真实圆角曲面映射为原角，相邻平面仍独立选择，其他角点优先于既有圆角面。圆角 hover 显示自身曲面；仅距原边 4px 内才让原边优先。
- 草图取点复用 `sketchOperationPoint`，但吸附目标必须是真实操作点而不是鼠标：单点拖动手柄、多选/形状平移的中心、线段另一端的方向锚点分别计算。精确点/原点优先，其次为平行/垂直方向，最后为单轴与交点；圆/椭圆中心与矩形/正多边形中心均为参考点。约束双方均可调整，固定点和当前操作优先级保持不变，重复求解不得漂移。
- 倒角生成面和圆角生成曲面在尺寸拖动时同样重绑 active；选中圆角曲面等价于选中其原角，可继续调整半径。相邻面推拉后仍使用本次重建解析出的角点，不退回普通面或邻边选择。边倒角最大值为截面最小尺寸，可覆盖整条边形成直角三棱柱；边圆角仍限制为截面最小尺寸的一半。
- 实体 face/edge hover 使用橙色高亮，选中使用深橙色；edge 使用独立粗线，不再用整个 Body 的材质变化代替。高亮遵守场景深度遮挡，选中曲面不会覆盖其他面。
- 3D 草图以完整封闭图形为 hover/选择单位，与共面的平面同时命中时优先选择草图；交叉区域以最小封闭交集面作为 active 轮廓，只拉伸该交集柱体。Shift 单击累加多个完整轮廓，整体拉伸通过 Union 只显示一个合并 mesh。
- face 高亮/选择来自当前 body 的 SameDomain 拓扑面片；edge 来自 logical edge graph，不使用三角形内部边。圆柱上下圆边为完整闭环，细分直线仍是一条逻辑边。
- 三维工具状态下，非手柄区域的左键空白或模型拖动均为 Orbit，包括移动、旋转、缩放工具；Command/Ctrl + 左键拖动才进入框选：从左往右只选完全包含的 Body，从右往左选择接触框线的 Body。
- 空格 + 左键拖动使用 OrbitControls PAN 平移视图；未拖动时松开空格仍可对悬停实体平面建立草图。
- 右键拖动 Orbit，中键拖动 Pan，Shift + 右键拖动也可 Pan；右键单击打开上下文菜单，普通滚轮缩放。
- 悬停实体平面时按空格，在该面建立草图并切换到正交正视图。
- 坐标球点击轴端点切换对应方向视图，拖动坐标球旋转相机。
- 草图 U/V 球不可点击，只有 N 可点击并恢复上 V、右 U 的标准视图。
- 点击只对实际命中的轴球生效，三维切换到对应 ±X/±Y/±Z，草图按平面基切换到对应 ±U/±V/±N；相机使用既有过渡，保持当前目标点与轨道距离。点击空白不再吸附到最近轴。
- 坐标球手势使用 `INTERACTION.clickTolerancePx` 区分点击与拖动，并统一处理 pointer capture 释放、`pointercancel`、`event.buttons === 0` 和窗口失焦，避免点击后相机粘住指针。
- 拖动坐标球接近主轴时，以点积阈值 `0.975` 磁吸到该轴，保持当前轨道半径。拖动状态始终保存未磁吸的轨道角，渲染吸附不得覆盖它，因此吸附后仍能继续拖离主轴；`gizmoOrbit.spec.ts` 覆盖该回归。
- 正负轴均显示对应 X/Y/Z 中等饱和配色和轴线，负轴端点仅降低不透明度；三维与草图坐标球、测量轴和移动/旋转/缩放 TransformControls 共用 `AXIS_COLORS`，控件每帧使用的缓存色同步更新。
- 草图平面坐标球拖动期间不做逐帧主轴吸附，右键旋转直接更新相机与 OrbitControls，避免主轴附近往返跳动。
- 右下角坐标轴双击在 3D 恢复斜上方透视、在草图恢复上 V 右 U 正交正视；世界/平面原点居中并适配全部内容，单击轴行为不变。
- 坐标球与比例尺距离画布底部 12px，共享基线。

## 测量

实现：`Viewport.setMeasureMode` 及 `Measurement mode` 分区。

1. 点击尺子进入 measure 模式，图标保持选中状态。
2. hover 第一个面时使用绿色三角形面高亮；点击后记录世界坐标点。
3. hover 第二个面时使用橙色高亮；点击后生成尺寸标注。
4. 两个点之间绘制总距离双箭头，并显示毫米距离。
5. 非零 X / Y / Z 分量分别使用红 / 绿 / 蓝双箭头和距离标签；零分量不创建标注。
6. 第三次点击清除全部测量标记，退出 measure 模式并取消图标选中状态。切换其他工具也会退出测量。

测量标记只存在于渲染辅助层，不写入项目模型数据。

草图模式使用同一底部测量按钮，但采用连续二维测量：启动时取消未完成形状和 Line 编辑；每个点均参与参考线匹配并受磁吸开关控制。第 2 点显示距离，第 n 点仅保留 n-1 与 n 的两个蓝色点、蓝色连线和距离标签，之前点线全部隐藏，测量不会创建草图实体。三维与草图测量中按右键都会退出测量并清除标记，右键拖拽继续控制视图。

## 比例尺与适配视图

实现：`Viewport.updateScaleBar`、`fitBox / fit`。

- 比例尺按相机到 orbit target 的距离、垂直 FOV 和画布像素高度，实时估算视图中心的 `mm / pixel`。
- 首页和草图共用底部按钮布局。测量左侧独立显示渲染、白模、线框、透视四个图标模式；选择写入 `lab:model3d:viewport:displayMode`，刷新后恢复，并以 divider 与测量分开；草图隐藏该组和 divider，强制渲染模式，退出后恢复此前模式。剖视按钮位于测量右侧，进入草图时退出剖视并禁用，退出草图后保持非剖视。
- 白模统一使用浅色实体材质，透视使用半透明实体。相机按钮打开 `FloatingPanel` 显示设置浮层，包含边线、地面投影、网格和正交/透视切换；浮层为半透明 blur、圆角、0.5px border，底部箭头指向按钮。工具栏不再重复测量、显示和实体树入口。
- 比例尺目标长度约 150px，按当前 Grid 的整数段分格；例如 4 段、每段 10mm 时显示 `4 x 10mm`，比例尺右移并增加 10px 顶部 padding。Grid 缩放变密时按 10 倍切换格距，每 10 格一条低强度粗线，粗线宽度 1.25、透明度 0.32，细线透明度 0.42。以 orbit target 为中心、当前视口宽度对应的世界半径为边界，200% 半径开始淡出，300% 消失。
- 点击 scale 图标时保持当前相机方向，仅沿该方向调整距离并居中模型。缩放上下限由当前可见模型和草图的包围半径决定，保留 20 倍完整展示余量，不再固定为 minDistance 5/maxDistance 1400。
- 适配动画时长 420ms，使用三次 ease-out；用户开始新的画布操作会取消动画。

## 投影

- 地面阴影默认关闭，不随项目保存。
- Display Modes 中的 Ground Shadow 只控制阴影接收平面、方向光投影和 shadow map，不改变网格或相机投影方式。
- Shaded / Wireframe / X-Ray、Show Edges、Isolate 和 Section View 只改变显示或视觉裁切，不写入实体尺寸；Section View 不等于 Split Body。
- Section View 默认使用穿过世界原点的剖面，底部居中滑杆调整位置；每帧从相机视线更新剖面法向，因此旋转视角时剖面始终垂直于相机；stencil 正反面材质共享该实时平面，不能使用 Material.clone() 留下的初始剖面副本。逐实体 stencil 端盖填充实心断面并保留内部空腔；原始表面在真实剖切平面内侧微量裁剪，端盖保持在真实剖切面上，避免与原始共面底面重叠。网格向地面下方偏移，剖视期间源实体双面显示并在退出后恢复；端盖使用不透明斜纹且在保留表面之后绘制，正常读写深度，从内部观察也能清楚区分实体截面。
- 滑杆范围是全部可见实体相对世界原点的最小包围球半径：最小值在任意视角保留全部实体，最大值裁掉全部实体。剖面到相机之间的部分以透明度 0.3 的独立轮廓显示，轮廓不属于拾取场景；射线同时过滤被裁区域，避免不可见部分被选中。

## 选择驱动的 UI 状态机

实现：`App.vue` 的 `uiState`、`operation`、`startExtrude / applyBoolean / editHistory`。

- `Default`：无选择，显示完整 Sketch、Construct、Transform、Tools 和布尔入口。
- `Sketch`：平面草图上下文，显示 Line、Rectangle、Circle、Arc，另一侧保留视图和约束扩展位置。
- 普通草图不显示顶部参数操作条，厚度、平面和点编辑不占用画布顶部；镜像、线性阵列、旋转阵列等明确流程的操作条除外。
- `SelectionAdaptive`：Items 或画布选择变化后的推荐状态。
- `ToolActive`：Extrude 或 Boolean 正在预览时显示顶部流程操作条；Face Extrude 只显示右侧自适应工具和箭头输入。
- `HistoryEdit`：从 History 重新打开已有 Extrude/Boolean，引用和参数在提交后写回同一实体。

顶部操作条只承载需要完成/取消的流程：默认、单选、多选、Move/Rotate/Scale 与 Face Extrude 均不显示；普通实体名称、尺寸、颜色及变换向量在右侧自适应面板编辑。Extrude 显示方向、侧面、拔模、结果/目标和 Done/Cancel，Boolean 显示运算、Target/Tool 交换、保留项和 Done/Cancel；草图仅 Symmetry 多步骤工具显示独立步骤条。所有操作条左对齐并允许字段换行。

3D 与草图均在右侧显示操作提示。3D 提示随测量、Extrude/Boolean、当前变换工具以及 Body/Face/Edge/Profile/Plane/多选状态切换，主要列出单击、双击、拖拽和快捷键；提示在右侧工具/约束面板下方的剩余空间中居中，不与操作面板重叠。

草图长度输入按线段方向 rotate 并在线上方偏移，单位下拉和数字输入缩短且不显示原生步进按钮。短直线低于 52px 投影长度时隐藏贝塞尔控制长度输入，仅保留线段尺寸。

实体面和实体边单击只选择并高亮，拖动面上的粗箭头才进入 Face Extrude；Body 通过实体树或双击选择后可 Move/Rotate。闭合 Profile 单击只选择，可拖动视图中的单个粗箭头或在箭头旁输入长度后按 Enter 进入 Extrude，负值用于反向。双击画布中的面选择完整 Body。

## Profile 与草图工具

实现：`profiles.ts`。草图与 Body 是不同的数据对象，但 Sketch 不在 Items 中占用实体条目。

- Line/Polygon：逐点放置，闭合后可用于 Extrude。
- Rectangle：两个对角点生成四个源顶点，创建后与普通 polygon 一样按边和约束编辑。
- Circle：源数据始终是圆心和圆周点，预览/导出时才细分。
- Arc：源数据始终是起点、经过点和终点；开放圆弧只生成线，不形成可拉伸 Profile。
- Exit Sketching 只退出草图并生成 Profile；它不是 Extrude 的 Done。
- 选中已有 Profile 可重新进入草图或 History；修改 Profile 后，引用它的 Extrude 自动重建。
- Normal to Sketch 使用当前平面法向恢复正视；进入 Extrude 后返回三维透视方向。

## Extrude

- 选择闭合 Profile（支持 Shift 多选）后出现单个正向粗箭头与长度输入；拖动生成实体，输入正/负长度并 Enter 立即按对应方向生成，点击箭头不拖动会取消预览。
- 拉伸以草图所在面为固定面，同一箭头向反方向拖过草图平面后自动切换生成方向；多个选中轮廓分别生成同距离 Body，重叠也不自动合并。贝塞尔边拆分后的闭合区域使用自身 body 计算箭头时，先恢复草图基准面再定位到拉伸顶面，箭头不得随深度额外远离顶面。
- 拖动 Profile/箭头方向或输入距离都会更新同一 `depth` 参数。
- 支持正向/反向、One-Sided/Symmetric、Draft Angle。
- Result 支持 New Body、Union、Subtract、Intersect；默认始终为 New Body，只有用户显式选择结果和目标后才执行布尔。
- 箭头侧面的长度输入与拖动共用同一 `depth`；空白提交和 Done 等价，Esc/Cancel 恢复执行前文档。
- 导出只包含 Body，不把辅助 Profile 面写入 STL/GLB。

## Face Extrude

- 所有完整平面区域都可以显示法向粗箭头，曲面和非同域相切面集不进入该操作。Box、Cylinder、Extrude 和 Boolean 的当前实体统一使用 Manifold Face Extrude。
- 正位移执行 Union、负位移执行 Subtract；切穿可产生空实体，不从背面反向生成实体，也不因接触其他 Body 自动合并。
- 箭头锚点固定手势开始时的 S0/F0/n0 和 revision。preview 只计算绝对距离，pointerup 重新求最终值；cancel、Esc 和失焦恢复 S0。
- 工具体直接复用选中面的真实三角形与边界环，支持凹面、孔洞和多组件结果；禁止凸包、smooth vertex normal 或仅移动顶点冒充。
- 粗箭头按相机距离和投影参数逐帧换算为世界缩放，屏幕长度固定为 `INTERACTION.arrowScreenLengthPx`；可编辑长度输入位于箭头侧面，支持正负值、Enter、失焦、方向键、滚轮和单位切换。输入值是本次手势初始状态与当前状态的差值，正值沿箭头方向。
- pointerup 烘焙后保留更新后的面锚点和粗箭头，下一次拖动以新提交状态为零点，不要求先让尺寸输入 blur；输入提交同样更新面锚点，Enter 后的 blur 不得重复应用同一差值。几何锚点已失效的旧箭头不得启动事务或读取空 vertices。
- 单击选择面，双击选择完整实体。选中面使用 active 色并做透明度呼吸；选中实体使用天蓝色并做亮度呼吸。
- 近似椭圆弧仍按曲面处理，不得因法线接近而误判为平面。`SurfaceDomains` 对 `analyticCurves` 中的 ellipse 返回 smooth domain，避免弧面平面推拉产生退化三角形；`trimmedEllipseExtrusion.spec.ts` 覆盖多种椭圆比例和两个真实矩形侧面的连续正负推拉。

## 草图图片与 SVG

- 草图渲染区接受图片/SVG drop。图片是独立可选实体，顶部/右侧显示宽高输入，四角用于拖动；SVG 多元素以文件夹整体选择，viewBox 四角使用同一交互。
- 两类资产的比例锁默认开启。锁定时修改任一尺寸或拖动角点会保持宽高比，解锁后独立变化；角点均参与其他草图操作的参考线和磁吸。磁吸目标是比例换算后的实际拖拽控制点而非鼠标；锁比例时选择满足约束的最近参考轴。
- 图片层级低于形状，图片之间遵循实体树先后顺序。SVG 按当前视图适配，基础图形保持对应类型，path 转成可编辑轮廓。

## Edge Fillet / Chamfer

- 未处理的直线实体边和三面角点可建立角修正。源边/角箭头朝外，负向（向内）拖动增大正圆角，正向拖动减小并切换为负倒角；箭头侧输入提交同一有符号绝对值。
- 非零角修正生效后，原边/原角的 active、箭头和热区立即移除。相邻面、边、角只显示并拾取最终拓扑上的剩余区域，不可见基础代理不再提供边/角热区。
- 角圆角只修改当前角的局部区域：以连续外凸 Bézier 曲面替换顶点，中心控制比例为 `0.87r`，与相邻平面相切并在距顶点 `radius` 的棱边位置终止；不得形成球体凹槽或中心内凹波浪，不处理入射整边、不生成圆柱，其他角和超出圆角区域的边保持原样。倒角生成平面和圆角生成曲面拥有独立 hover/选中 active，且优先于附近边界。倒角在面中心沿平面法线显示粗箭头；圆角在点击位置沿实际曲面三角形法线显示粗箭头。继续拖拽或输入只调整原 treatment，不创建推拉实体。
- 圆角生成后，原角点和三条入射原边仍可选择：原角热区优先选角，其余入射边位置优先于同体圆角面。原角保留半径编辑箭头，入射原边可继续添加边圆角/倒角；代理不显示几何、不进入导出，也不恢复其他已删除源边的热区。
- 当前边/角存在非零角修正时，详情面板提供“复原倒角/圆角”，点击将尺寸归零并恢复未处理实体。普通相邻最终边/角不会继承附近 treatment 的复原入口。
- 面偏移仍通过剩余基础面引用执行，选择反馈只高亮最终剩余面域。相邻面移动后处理边重新定位到新公共边，角点处理固定排在邻接边处理之后；Esc/取消回滚当前手势，烘焙不会重复切削。

## Boolean 执行态与 History

- 两个或更多 Body 可从 Transform 下方的并集/差集/交集组进入草稿。进入时不改变相机，只临时显示参与区域并隐藏无关模型；隐藏素材也会在临时预览层重建，不写入 document。
- 完成前不创建结果实体、不显示最终模型，实体树保持原样。完成或点击空白才一次性创建并烘焙结果、隐藏素材并恢复无关模型；Cancel/Esc 恢复原展示和选择。
- 按 Venn 成员关系将参与模型拆成独立区域，每个区域显示透明材质、对应色边框和始终面向相机的 mini 按钮。`+` 统一紫色，`-` 为深红色；点击只切换临时 `regionSigns`，不修改源实体。
- Union 默认所有区域为 `+`；Subtract 默认只有主模型非交集区为 `+`，其余为 `-`；Intersect 默认只有全成员交集区为 `+`，其余为 `-`。完成时仅合并 `+` 区域，不再按整模型自动切换操作类型。
- 多个交集区域各自独立控制，不单独渲染一种紫色交集结果；区域预览本身没有选中呼吸或面/边 hover，只有 mini hover 时对应区域呼吸。
- 全部区域均为 `-` 时禁止完成，点击空白不执行任何操作。操作条只提供“保留目标”和“完成”，通用关闭按钮为圆角矩形；保留目标只保留主模型源实体，其余素材隐藏。空白完成同时允许 OrbitControls 收到 pointerup，避免导航粘手。
- History 回改复用同一临时预览和提交流程，已有结果在编辑期间不作为额外模型渲染。

- Shift 范围选择仅覆盖同一父级的起止点及其中间节点，跨文件夹只选后点节点。草图标题独立于 3D，特殊模式不显示数量或文件夹按钮，实体统一使用 cube 图标。

- 再次点击当前工具只展开或收起 Parameter Card，不退出工具；单击不修改几何，拖动或数值输入才产生编辑。

- 平面是 Items 中的独立对象，支持点击选择、眼睛显隐、Move/Rotate Gizmo；Scale 对平面禁用。

- 默认工具栏向左收起，带文字的画图工具栏向右进入；Exit Sketching 保存有效闭合形状或退出未完成绘制。Constraints 独立显示在画布右侧，支持方向、平行、垂直、等长、边长固定和点/边固定。点与边选择互斥，方向关系只接受真实直线；固定边会固定其全部端点，含固定点的形状不能通过中心抓手整体移动。固定长度按各边当前值独立保存，端点拖动只做圆周运动。

- 逻辑边的选中点与约束锚点使用实体顶点索引，不复用局部端点 0/1；正方形等长关联边统一联合求解，不再额外重建角点。贝塞尔控制柄随端点边的归一化局部坐标平移、旋转和缩放，只有直接手柄拖动可改变相对曲率。

## 绘制形状与贝塞尔编辑

- 拆分线形成闭合区域时，退出草图仍显示视口专用填充面并可点击该区域；预览不导出。
- 拆分线组成唯一闭合区域时，可从任一组线拉伸；区域始终闭合，且不得继承单条线的 open 状态或曲线索引。普通点击开放线仅选择，不进入面编辑。
- 标准封闭形状填充区可点击选择整形并显示 grab，拖动时整形、封闭面和中心手柄都按草稿点实时跟随；标准形状发生交叉时仍保留各自完整封闭面，交叉区域继续单独生成；所有语义点、计算中心点和贝塞尔控制柄分别参与整体参考磁吸，排除自身并采用最小位移修正；中心也注册为其他形状的参考点，裁剪/拆解后移除。其他封闭区域交互不变。
- 矩形/正多边形创建完成后立即转为共享端点的 `polygon` 边：矩形保存邻边正交，正多边形保存各边等长及邻边有向夹角。后续编辑统一走 Line/Polygon 端点和约束逻辑，不再按中心/半径维护形状，也不在曲线编辑后拆分实体。

实现：`profiles.ts`、`Viewport.updateSketch` 和 App 的 sketch drag/handle 回调。

### 参考线与磁吸

实现：`sketchGuides.ts` 负责候选计算，`SketchGuideController` 负责屏幕距离换算，`sketchReferences` 独立叠加层负责临时显示；`SketchRulerOverlay.vue` 与 `sketchRulers.ts` 负责标尺和持久参考线。

- 单点绘制、顶点/半径/贝塞尔控制点拖动时，对其他草图的语义参考点生成水平、垂直参考线；整个当前形状均排除，禁止自参考。其他矩形的对角中心也作为参考点。
- Line 正在形成边时，额外对草图中的所有真实直线生成平行、垂直参考线；曲线及其细分点不作为直线参考。
- 水平、垂直方向分别取进入阈值的最近匹配；两个方向同时命中时吸附到交点并同时显示两条参考线，单方向命中时保持最近单条匹配。阈值由 `INTERACTION.sketchGuideSnapPx` 配置，并通过当前相机换算为平面距离，缩放后保持相同屏幕磁吸范围。
- 约束区“关联检查”下的磁吸开关默认开启；关闭后参考线和高亮继续显示，但绘制与拖动使用未吸附的指针坐标。
- 参考线只在按下绘制或拖动时出现，普通悬停不显示，pointerup 后清空。
- 参考线为穿过参考点或当前边起点的绿色虚线，对应参考点/参考直线以 `SKETCH_COLORS.reference` 高亮。无匹配、拖离、pointerup、退出草图或开始视图操作时清空叠加层并恢复原色。
- 扇形角度拖动不使用 Cartesian 参考线，保持原有参数角和角度磁吸行为。
- 草图上、左 12px 标尺的 0 刻度与平面局部原点投影一致，主刻度使用 1/2/5 十进制步进并十等分为长/中/短刻度，数字放在主刻度线侧方。顶部拖出水平线、左侧拖出垂直线；参考线保存为当前 `SketchPlane.guides`，以虚线长期显示，不参与封闭面或实体生成。
- 持久参考线可选中拖动，Delete 删除；选中后在对应标尺位置显示红底白 ×；位置输入使用独立绿色底和“参考”标签并内移 18px，左侧与刻度文字同为 rotate(-90°)，避免遮挡标尺数字。输入支持负偏移，Enter/blur 写回且同一值不重复记录历史。U/V 参考线同样参与单轴和双轴交点磁吸；拖动参考线本身时始终硬吸附最近主刻度值（短刻度仅显示；主刻度 1mm 时只允许整数毫米，不再由其他参考点改写成小数），排除自身并取最近候选，开关行为与普通参考线一致。hover 按方向显示 col-resize/row-resize；绘制工具活跃时参考线不拦截点击，创建形状输入优先，仅选择工具可拖动；操作点/控制柄和草图边始终优先于参考线，参考线在操作点周围镂空；拖回标尺或拖出视口边界释放时删除。

- Line/Arc：逐点连接或直接拖出一条线。点击线段生成两个三次贝塞尔控制点，拖动控制点将线段改为曲线；虚线显示控制链。双击某个控制点将其恢复到所在直线；拖动端点时，原本共线的控制点仍保持共线。
- 矩形：对角两击或拖拽生成四个轴对齐顶点，完成后转为 polygon，并以邻边正交约束保持矩形。
- 圆：圆心 + 圆周点；两点或拖拽创建，圆心到圆周使用虚线辅助半径。
- 椭圆：圆心 + X 半径点 + Y 半径点；拖拽时以起止点两个分量生成三个源点。两个半径向量保留顺/逆时针方向，扇形角使用椭圆局部参数角。
- 正多边形：中心 + 外顶点 + 边数，支持正三角形、正方形、正五至正八边形；完成后转为实际周角点、各边等长和 `360° / 边数` 邻边外角约束，不再保存中心/半径编辑语义。
- 所有闭合形状显示半透明斜纹填充，普通 3D 视图与草图编辑态一致；斜纹直接合入填充材质，不增加可拾取的覆盖面。源点、曲线控制点、边数与 `planeId` 一并保存，选中平面可继续编辑。
- 创建成形后保持选中并显示操作点与长度输入；再次点击同类工具才开始下一个形状。Esc / 右键只结束当前路径或取消选择，Exit Sketching 才退出草图。
- 切换已有形状后 300ms 内忽略操作点输入，避免 A/B 切换时旧 pointerup 在新形状上创建或移动点。
- 300ms 保护在 pointerup 也消费本次指针释放，修复其他形状切到 Line 时第一次点击追加点的问题。
- 空白左键拖拽继续绘制形状；右键或平面坐标球旋转视图，空格拖拽仅平移且不产生草图编辑。
- 草图边使用 Line2 黑色粗线，已保存但未选中的轮廓也在场景同步时添加同样的边线。
- 粗边只在草图模式生成；编辑时隐藏其他 Body、其他平面草图和区域填充，避免拾取被非草图模型干扰。
- Alt/Option + hover border 使用 `sketchBorders.ts` 计算交点区间并标红，点击删除该区间；普通段转开放 Line，Bezier 段保留分割后的控制点，圆/椭圆保留参数化圆弧。开放圆弧与直线可按端点重闭合，两段轮廓也能组成封闭 Profile。
- 非 Line 形状的中心点平移整个形状；Line 点使用 Alt/Option + 点击删除，并同步重排 curves 与 lockedPoints。
- 选中形状与 hover 统一使用 active 色；操作点有描边，hover/拖拽显示抓手，Alt 删点显示透明红色与删除光标。边框 hover/选中使用更深的 active 色。
- 长度输入 blur 后延迟写回，避免 Vue 覆盖层在 blur 中同步重建导致输入焦点和节点状态异常。
- 长度和角度输入按 Enter 时立即写回，不必等待 blur。
- 右键点击已有草图提供删除与取消选择；右键拖动仍只旋转视图。删除前检查 Extrude 引用。
- 长度输入统一显示两位小数和单位（mm / cm / m），blur 后写回；项目数值不随单位切换换算，单位只改变展示和导出语义，当前单位以 `lab:model3d:sketch:lengthUnit` 作为新项目默认值。
- 长度和角度的步进为整数；小数值通过按钮、滚轮或方向键操作时，先向对应方向取整，再增加或减少 step。非 hover/focus 的尺寸输入以 50% 透明度显示并平滑过渡。
- 矩形宽高等边尺寸的锁直接排列在单位右侧，与数值输入共用同一旋转容器，因此不会遮挡数值。没有尺寸的边锁居中于对应边，视图缩放不会增加锁的额外偏移。
- 非 360° 圆/椭圆在逻辑边中拆为起始半径、解析圆弧和结束半径，封闭面正常生成，半径与圆弧可独立删除和交叉裁剪。圆与椭圆额外保存 `sectorAngle`。黄色扇形点沿 CCW 方向改变扇形角，吸附到整数角度并在 90° 倍数附近增强磁吸，双击恢复 360°；半径、椭圆双半径、矩形长宽、多边形半径和线段有对应输入。贝塞尔控制链只显示虚线与控制柄，不提供长度输入。

## 显隐与底部辅助图标

- 所有 Items（实体、文件夹、平面）都有眼睛。文件夹显隐递归应用到整个子树。
- 测量使用带刻度的 ruler 图形。测量和适配按钮不显示底板，激活状态仅通过图标颜色表达。
- 左下状态未选中时显示全场景实体与三角形数量；选中后显示所选实体/面数量、对应三角形数量和两位小数的世界轴包围盒 XYZ 尺寸。
- 剖视保留相机垂直剖切与原点范围滑杆，并使用 stencil 封口平面显示带斜纹的实心断面；内部表面在剖视期间双面渲染，断面只是渲染辅助，不写入实体数据。

## 实时记录、正交绘制与手势结束

- 圆、矩形、椭圆、正多边形在定义点完成或拖拽 pointerup 时立即创建 Profile，并触发 IndexedDB 自动保存；无需 Close。
- 成形后保留当前图形为选中编辑态；Esc 取消选择后才可开始另一段 Line，选中已有 Line 后左键点击才可追加点。所有图形实时写入。
- 草图相机使用独立 OrthographicCamera，退出后恢复 PerspectiveCamera。比例尺在草图中按 `(top - bottom) / zoom / canvasHeight` 计算，反映该平面的真实单位。
- 草图模式隐藏有限平面边框，以平面底色铺满画布，网格旋转到当前平面。坐标球、测量、显示设置、适配按钮与比例尺布局同首页保持一致。
- 封闭区域的平行线填充使用平面 UV 坐标，旋转视角不会改变纹理方向；线宽、间距和不透明度集中在 `SKETCH_STYLE`，普通 3D 草图和剖视端盖复用同一 `HatchMaterial` 注入实现。
- 草图右键拖拽只绕平面法向做二维 roll，不改变为正交三维轨道；三维 Orbit 在草图中禁用。
- 形状完成或右键结束当前操作后自动切回选择工具。Line 两个点、Arc 三个点即可作为独立开放轮廓保存，不要求闭合；显式完成三点以上的 Polygon 时才形成封闭 Profile。
- “线条 / 曲线”的 `polygon` 开放轮廓和独立 `line` 都与两次点击共用最终写回路径，右键结束编辑不得删除已经完成的拖拽 Line。
- 参考线包含平面原点及世界原点投影到当前平面的位置；原点参考使用普通 guide 色，不显示参考色标记。
- 平面坐标球拖动与右键使用独立的二维手势：以平面原点或坐标球中心为圆心，计算前后指针向量夹角，按同方向、同角度绕 N 轴 roll；相机位置保持不变，不使用 3D 轨道或像素速度估算。
- 退出草图时清空 face 选择、实体树选择和几何锚点；完成草图后仅按既有流程选择新轮廓。
- 裁边采样会去除重复端点和零长度边，`sketchRestitch.ts` 先合并连续开放链再提取闭环；平滑圆弧在 border 选择中保持为一条逻辑边，可重复裁切而不碎成多个实体。
- 圆周交点区间按环处理，允许删除跨过 0°/360° 的弧段；落在采样顶点上的交点也计入区间，避免漏掉第二个交点。
- 重连结果通过 `controlPoints` 区分真实交点/拐角和内部采样点。仅控制点生成操作手柄，圆弧采样不再生成逐点尺寸输入，也不作为直线参考。
- 控制点拖动期间只更新本地预览，文档写回和完整场景同步在 pointerup 一次完成；预览渲染按动画帧合并。
- 所有绘制/控制点/视图拖拽使用 Pointer Capture。草图 pointerup 在通用“移动超过点击阈值”判断之前完成，因此画布外松开和 pointercancel 都不会留下粘连草稿。
- 自定义 SVG 图标由 `SvgIcon.vue` 维护，当前铅笔和尺子使用 currentColor，可直接修改 SVG path 而无需图标字体。

## 封闭面与裁剪逻辑边

- `sketchFaces.ts` 在全部交点处分割边，并用有向 half-edge 遍历有界区域；每次场景同步和逻辑边写回后重新计算，不再只依赖实体的 open 标记。
- 面 hover 只切换独立面网格的 active 填充色，点击面不选择形状；面层级低于 border 与操作点。
- 未裁剪 border 选择整个形状，已裁剪 border 进入独立逻辑边编辑。裁剪直线仅显示两端和长度，端点可编辑且保持直线；连续曲线仅显示首尾，拖动任一端整体平移。
- Line/Arc 的第 n 点只连接 n-1，开放路径不补首尾边；所有真实 Line 均参与平行/垂直参考线。
- 草图 border 使用 4px 屏幕线宽，操作点为原尺寸的 60%；border hover 与面 hover 互斥，模型层和编辑层的 border 按实体去重后拾取。面内平行线不透明度为 50%。

## 草图高级镜像、线性阵列与二维变换

- 左侧基础工具下方依次为“高级工具”和“变换工具”分组。“镜像”入口启动三步顶部操作条：设置数量/偏移、选择单个素材扇区、绘制并选择轴对称或旋转对称；数量对应从原点出发的射线数，3 重为 120° 三射线，4 重为十字；奇数数量自动使用旋转对称并禁用轴对称，偶数数量可选两种方式；最后一步主按钮变为完成，右侧始终提供红底圆形白 X。
- 第一步和第二步禁用所有草图工具；第三步开放基础绘制、平移、旋转和缩放。未选中扇区显示 50% 浅色遮罩，hover 扇区显示独立高亮，源草图在整个对称过程中只读淡显。
- 对称只处理选中扇区内的内容。轴对称以分界镜面复制，旋转对称按顺时针复制；完成后所有结果合并为一个复合草图并选中，只能整体选择，不进入逐边编辑；取消则完全放弃临时平面。
- 选中完整形状后，“高级工具”出现“线性阵列”：操作条输入新增复制次数 n 与单步间距，拖动末端箭头确定固定方向和总跨度，实时预览但不修改原图。方向支持 U/V 轴、其他草图边与参考点磁吸，并显示方向参考线；完成保留原图并新增 n 个独立草图，取消不产生历史。旋转阵列提供中心手柄、复制次数、总角度和反向按钮；中心仅吸附其他形状的明确端点/控制点，不吸附推断中心或轴向投影；360° 时源形状与副本共同等分整周，避免 360° 重叠加。两类副本均按原名称连续编号。
- 平移使用加粗 X/Y 轴箭头与坐标输入，手柄随形状移动；旋转使用加粗圆环、角度输入及可拖动中心点，手柄随角度移动；缩放使用加粗四向箭头、比例输入及可拖动中心点。输入放在手柄外侧，高级工具激活时隐藏旧尺寸覆盖层。中心默认是选中内容包围盒中心。中心拖动受“参考线磁吸”开关控制，可吸附原点和其他草图参考点，并显示参考反馈；自身矩形角点、圆半径点和其他草图参考点均参与吸附。
- 第三步提供与普通草图一致的浅色网格、平面坐标轴和右键二维旋转；Alt + hover 预览交叉边删除区间，点击只修改临时素材；选择工具点选临时形状后显示中心与控制点，可整体移动、拖顶点或调整半径。
- 所有高级工具数值输入支持滚轮调整，滚轮不得冒泡为画布缩放。
- 选择工具在空白处拖动显示框选框，完整包含的形状、逻辑边和点按优先级多选，Ctrl/Command 追加；底部红色删除分组仅在有选中时动效出现，点击只删除选中的形状、边或点并保留其余约束。
- 三种变换均支持先选工具再点选形状，或先选形状再切换工具，激活时同步重建手柄中心；操作边时中心默认在边起点，已选端点时优先使用对应端点。输入支持 Enter、失焦、方向键和滚轮写回，长度使用单位选择、角度为 deg、缩放为 x；拖动以初始快照计算并同步普通草图层，所有语义顶点、曲线控制柄和中心均参与平移/旋转/缩放反算磁吸；滚轮和右键仍可控制视图；Esc 优先退出线性阵列或镜像，否则维持原草图取消选择行为。

## 实体拓扑与面/边编辑

- 单击实体默认选择完整连通的 SameDomain 面片；不连通的共面岛、只共一个顶点的区域和薄壁另一侧不会被一并选中。圆柱侧面跨 seam 仍为一个 logical face，端盖保持独立。
- 实体边来自拓扑而非 `EdgesGeometry`：箱体内三角剖分对角线不可选；被细分的直线、圆柱上下圆环命中完整 logical edge。边拾取按 CSS 像素计算，并默认优先未被遮挡的候选。
- 面或边的自适应面板提供“相切扩选”和“穿透选择”。相切扩选沿真实拓扑连续性传播，遇分叉停止；穿透选择不影响显示模式。
- 选中平面后拖动粗箭头；自适应面板不再重复提供“推拉面”入口。该操作是 Face Extrude，不是通用 Offset Face：向外加料、向内减料，只修改当前 body，接触其他 body 不会自动合并。
- 拖拽预览始终基于开始时的已提交实体；松开后按最终距离重新求解并烘焙。Esc、pointercancel 和失焦取消本次操作，Undo/Redo 恢复对应实体网格与拓扑引用。

- 草图拉伸或 Boolean 完成后，结果使用自己的烘焙网格。源草图/源实体仍可存在用于 History 回改，但修改或删除源对象不会暗中重建已提交结果。
- 删除源对象不再被依赖关系阻止；结果保留，失效的 History 引用随源对象一起解除。删除 Boolean 结果时仍按保留策略恢复源实体的可见性。

- 3D 草图在普通状态和 hover 状态都保持可见；退出 hover 恢复原始线色/填充透明度，不能恢复为编辑态的透明占位值。
- 实体默认中性灰色展示，不使用默认贴图或环境反射贴图；选择、hover、Boolean 角色色仍按交互状态显示。
- 圆柱与箱体并集后的不同平面、同一平面连续正负拖拽均必须保持位置和体积契约；共面碎片先经内核清理，无法验证的结果不提交。

- 圆柱侧曲面等 smooth patch 不提供平面推拉箭头；圆柱/矩形接缝处的真实平面仍可正常选择和拖拽。
- Boolean 结果使用内核生成的锐边法线，平面不得因邻面法线平均而出现类似贴图的云纹。


- 面拖拽 preview 与放手后的 committed mesh 必须保持相同三角化、锐边法线和拓扑，不需要拖动另一张面来补合并。
- 边 hover 与选择引用同一逻辑边；接缝圆弧按有序路径高亮，不跨圆跳接。遮挡边默认不抢占，Select Through 可显式选择其余边。
- 完全切穿是合法的空实体结果。布尔失败、无效索引、非闭合或定向错误不会提交为当前模型。

- 重叠但未融合的标准形状允许从多 `entityIds` 面候选中整选；trimmed 后才禁止整选。外部拖动改变尺寸后，输入框清除旧 raw 草稿并显示最新值。

## 高级实体工具

- 选中一个实体 Body 或实体平面后，Transform 分组前显示“高级工具”分组和“抽壳”。Body 不选面时保留全部外面，仅生成封闭内腔；选中一个或多个平面时在对应面开口。草图面、图片、边、角点及非平面不显示该工具。
- 实体面支持 Ctrl/Command＋单击累加选择，重复点击已选面只取消该面，不会取消整个 Body；所有已选面保持独立高亮。不同实体的平面也可分别成组执行抽壳。
- 点击“抽壳”进入两步操作，顶部 OperationBar 显示厚度长度输入与完成按钮。厚度输入立即更新，实时预览经 120ms 合并计算以避免连续输入卡顿，不修改 document、不自动保存也不产生历史；输入 blur 或 Enter 视同点击完成，但点击操作条内完成/取消时必须先抑制 blur，取消不得被误提交；点击完成才一次性烘焙实体并写入一步撤销。取消、切换工具或开始新选择会丢弃未提交预览。
- Shell 使用实体内缩体形成均匀壁厚，每个选中面使用内缩一个壁厚后的开口边界贯通内腔，保留外轮廓和相邻侧壁，增大厚度不得使整体缩小；相邻选中面的公共边同步打开，不能在开口之间留下梁；非共面相邻面按旧交互整面贯通，正五边形等斜角连接既不留梁，也不能形成额外 V 形凹陷。修改壁厚始终从操作前实体重新计算，不在已有壳体上重复抽壳。剖视封口同时处理预览与完成后的壳体，内外表面共同参与 stencil，壁截面使用高对比且正常读写深度的 cap 材质，不能只显示内表面。壳体内底面使用普通粗箭头面推拉，沿内法线拖动会填充完整面区域并增厚整个底部，不创建局部凸台。

## 草图变换与几何约束

- 单选圆、椭圆、矩形或正多边形时，旋转和缩放中心默认与形状自身中心重合；多选或无中心形状仍使用组合包围盒中心，手动拖动中心后不自动重置。
- 选择圆/椭圆边或相关曲线组合后显示“相切”；全部选中对象都有语义中心时显示“同心”。新规则与直线规则一样持续参与求解、固定点保护、关联传播、hover、删除和撤销。
- 约束面板按方向、几何关系和固定分组排列，按钮使用无边框样式。全部规则仅展示选中形状或选中边拥有的规则并显示数量，无选择或无规则时隐藏整个区域；列表独立滚动，滚动条有专属布局空间，不能遮挡每行右侧删除按钮。


## 本地 Agent / WebMCP

- 页面加载完成后通过 `navigator.modelContext` 注册项目、实体、草图、生成、工具和历史六个工具域；不支持 WebMCP 时使用 `window.model3dMCP`，两种入口返回相同的结构化结果。
- Agent 可以创建和编辑语义草图、参数化生成实体、检查 `faceId`、执行拉伸/布尔/抽壳/面推拉及撤销。所有修改与手工操作共享场景、保存和撤销状态，详细参数见 `docs/WEBMCP.md`。


## 车削与批量拉伸

- 仅选中封闭草图或一个明确平面时显示“车削”，整个 Body 不提供入口。启动后固定截面，用户必须点击共面的草图直线、实体线性边或选择网格轴；未选轴不生成预览且不能完成。Angle 默认 360°，轴向位移可选，预览后完成才写入历史，取消不修改模型。
- 截面随 Angle 绕明确轴扫掠形成实体，小于 360° 为局部实体，非零轴向位移可形成螺旋。轮廓不能跨轴进行部分扫掠；完成后生成实体，草图来源隐藏，Body 平面来源保留。
- 多选封闭草图时，每个轮廓显示独立粗箭头，拖动任意箭头批量拉伸全部轮廓。3D 提示包含 Command/Ctrl + 拖动框选多选。

- 实体参数面板不显示“厚度”；拉伸深度只通过拉伸流程或粗箭头调整，避免与抽壳、车削等操作冲突。
