# model3d 开发要求

本文件记录 model3d 的通用交互与交付约定。新增或调整功能时同步更新本文件和 `INTERACTIONS.md`，并遵守仓库根目录的 `AGENTS.md`。

> **当前阶段约定：在用户明确宣布“正式完工”之前，不需要兼容旧项目数据，也不编写旧数据迁移或回退读取逻辑。** 可以按当前交互目标直接调整数据结构和清理旧功能；存储隔离与禁止破坏性清理的规则仍然有效。

草图编辑的独立交互契约维护在 `docs/SKETCH_EDITING.md`；修改草图行为时必须同时更新该文档。

## 方案变更与回归

- 任何交互、几何表示、求交、裁剪、重连或约束方案变更，必须在同一提交同步更新 `DEV.md`、`INTERACTIONS.md`、`docs/SKETCH_EDITING.md` 和 `docs/REFACTOR.md` changelog；文档与实现不一致视为未完成。
- 已踩过的边界条件和历史坑点必须同时留下 spec 回归与源码注释，说明触发条件和正确约束，禁止只靠临时浏览器验证或下次重新调参。
- model3d spec 使用 Node 原生 test，通过 `node src/model3d/run-tests.mjs` 执行；解析曲线、交点、圆周接缝、裁剪和重连变更必须先补失败用例，再修改实现。

## 交付

- 只修改 `src/model3d/` 与构建生成的 `docs/model3d/`，不带入其他页面或无关文件。
- 默认不启动本地 serve。完成后执行 `yarn build model3d`，检查变更范围，再 commit、push。
- 构建产物必须是相对资源路径；不手改 `docs/`、页面 `<head>` 或其他页面产物。

## 工具栏与文案

- 可见文案使用简洁中文；单位、格式名和快捷键除外。导出入口统一称“导出”。
- `.tool-group` 中的工具按钮统一为白底、边框、圆形图标按钮，不在按钮外套 Naive UI Tooltip。
- 工具按钮通过 `data-label` 提供名称，hover 时标签向右侧以 translateX 动效展开。
- 3D 与草图左侧工具栏宽度统一为 120px；可见工具 title 不超过 5 个字，不允许为了容纳长文案加宽工具栏。
- 3D 工具栏上部和下部是独立 `.toolbar-section`，父级贯穿区域不接收指针事件，中间空档必须直接命中渲染层。搜索、插入、构造平面和工具打开与草图一致的左侧弹层：顶部为关闭，下面为命令或形状选项；自适应实体参数仍位于右侧。
- 3D 工具栏顺序固定为构造平面、草图、插入、导入，不再显示搜索和工具。插入提供立方体、圆柱体、球体、圆锥体和圆环；导入直接打开文件选择，支持自包含 STL、OBJ、GLB 网格并作为当前项目实体加入。项目 YAML 导入只保留在项目菜单。实体树中的所有实体统一 cube 图标，文件夹和平面继续使用各自图标。
- 首页工具栏只保留建模与变换入口；测量统一放在渲染区底部，显示与相机设置合并到底部相机按钮，实体树不再提供工具栏开关。测量左侧以 divider 分隔渲染、白模、线框、透视四个图标显示模式；草图编辑隐藏该组和 divider，并强制渲染模式，退出后恢复此前模式；显示模式通过 `lab:model3d:viewport:displayMode` 持久化，刷新后恢复，非法/已移除值回退到渲染。
- 选择面后的自适应面板固定在右上角，不重复显示厚度或推拉面入口；搜索、插入、构造平面和工具的二级面板切换使用统一滑动/淡入动效。命令弹层、自适应描述和所选实体参数由 `ToolPanels.vue` 维护；顶部流程操作由 `ModelingOperationBar.vue` 维护，不在 `App.vue` 重复模板。
- `OperationBar.vue` 统一顶部操作条结构和右侧红色 X，内部字段通过 slot 组合；对称与建模操作条必须复用该组件。操作条从工具栏右侧开始左对齐排列，空间不足时字段换行，不以画布中心为基准挤压布局。
- 普通草图不显示顶部操作条；只有对称等明确的多步骤草图工具可以在独立覆盖层中使用 `OperationBar`。
- 3D 默认、普通选择、多选、移动/旋转/缩放和面推拉不显示顶部操作条；只有 Extrude、Boolean 与 Shell 的执行/历史编辑流程显示。Extrude 保留方向、侧面、拔模、结果、目标和完成/取消；Boolean 只保留目标与完成/取消，距离统一在箭头旁编辑；Shell 保留厚度、实时预览和完成/取消。
- `AppButton.vue` 按 primary/secondary/danger/ghost、small/medium 和 disabled 统一圆角矩形按钮。OperationBar 关闭、建模完成和草图步骤按钮必须复用，不再使用圆形关闭按钮。
- 移动、旋转、缩放直接放在独立工具分组，分组上下增加间距，不再藏入“变换”二级菜单。
- 菜单项使用图标＋操作名／短说明，不使用整行 hover/active 背景色或大面积白色工具条背景。
- 补充说明优先使用合适位置的 info 图标＋hover，或局部 Tooltip；不在底部重复罗列鼠标操作，不显示坐标系说明。右侧操作提示由 `ViewportHints.vue` 统一布局，3D 根据工具、选择类型和操作流程切换内容，并避开右侧工具面板。
- 草图提示只显示当前绘制工具或当前选中/编辑形状对应的操作，移除混选说明；Line 连接首尾提示只在 Line 工具或编辑 Line 时出现。
- 粗箭头数值输入提交后保留已接受草稿，Enter 后的 blur 不得重复提交；新选择或画布手势清理旧草稿。所有 range 统一使用 `MinimalRange.vue`：3px 横轨道、竖线手柄、可传入轨道色和手柄色，默认主题色；剖面使用主题色轨道，约束检查使用白色轨道。

## 布局与状态反馈

- 不设置顶部项目栏。项目名、保存状态、撤销/重做、帮助和导出统一并入 fixed Sidebar；Sidebar 默认/最小宽 218px，可通过右缘拖拽或方向键调宽，最大为视口宽度的 1/3，宽度通过 `lab:model3d:layout:sidebarWidth` 持久化。使用纯白背景，不使用渐隐过渡。导出放在实体树下方、项目区上方。
- Canvas 从页面顶部铺满整个页面高度，只在左侧扣除 Sidebar 当前宽度，不参与顶部栏或其他悬浮工具的高度计算。
- 实体树为空时只显示空状态，不再渲染占满剩余高度的根级拖放区，避免空状态与树的 `min-height: 100%` 叠加产生滚动条。
- 单位放在渲染区右上角，通过下拉切换全局 mm/cm/m；模式徽标可与单位同区展示，不保留空的面板容器。
- 参考尺和坐标系贴近渲染区右下角，当前统一 bottom 12px。
- Grid 使用局部平面 shader 坐标，格距在每个数量级只取 1 和 5（如 0.1、0.5、1、5、10、50），每 5 格一条较粗线；粗线宽度 1.25、透明度 0.32，细线透明度 0.42，必须弱于坐标轴和模型。原点 X/Z 轴分别使用 `AXIS_COLORS.x` / `AXIS_COLORS.z`，不再沿用普通主网格色。以 orbit target 和当前视口宽度对应的世界半径为准，200% 半径开始淡出，300% 消失，避免远处线条堆积。
- 比例尺目标约 150px，按整数 Grid 段数分格，右侧显示 `${segments} x ${gridSize}${unit}`，不再使用 1/2/5 序列估算长度；位置适当右移并增加 10px 顶部 padding。
- 渲染统计使用半透明黑色胶囊，放在渲染区左下角；不占满整行。未选中时显示全场景 Body 数和三角形数；选中实体/多选时仅统计所选 Body 并追加世界轴包围盒 XYZ，选中面时统计该面的三角形与包围盒。尺寸按当前单位保留两位小数。
- 实体树使用终端 `tree` 式连续竖线、分支和末节点短线表示层级，不能只靠缩进表达父子关系；实体统一使用 cube 图标。
- Shift 点击只在同一父级内按显示顺序选择起止范围及其中间节点；跨文件夹时只选择后点击节点，草图多选同样遵守。点击树空白取消选择。选中节点同层时，新建文件夹放在该层并归入全部选中元素，否则在根层创建。支持拖到根级空白区，行前行后及根级横线指示释放位置且不占布局高度。草图及特殊模式树标题为“草图”，隐藏数量与文件夹按钮，仅普通 3D 视图显示文件夹按钮；实体统一使用 cube 图标。
- 仅已选节点的 `.object-name` 再次单击会原位替换为 input，默认当前名称；Enter/blur 确认，Esc 取消。直接双击名称或行都执行节点默认激活，例如编辑平面草图。名称单击通过短延时区分双击，不能在第一击提前进入重命名。
- 自动保存不展示常驻文案，只在保存期间于项目名旁显示 loading，完成后消失。
- 参考尺的适配按钮只显示“适配视图”，不附加括号说明。缩放上下限根据当前可见模型与草图的原点包围半径动态设置：透视距离为半径的 0.03–20 倍（保留最小值），正交 zoom 为 0.05 到 max(20, 100/radius)，保证 20 倍完整展示余量。

## 相机与选择

- 非工具状态下，普通左键拖拽与右键拖拽一样用于相机环绕；左键单击仍用于选择面、边或轮廓。
- Command/Ctrl＋左键拖拽才进入框选；框选仍区分完全包含与接触相交。
- 空格＋左键拖拽用于平移视图（OrbitControls PAN）。右键保持环绕，中键保持平移，滚轮缩放。
- 构造平面蓝色示意面片仅沿自身法线负方向偏移 0.03 显示单位以避免与 XZ 平面共面闪烁，`plane.origin`、草图和实体生成位置不变。参考尺旁提供透视/正交相机切换，默认透视；切换时保留视角与目标点，草图退出后恢复此前投影。显示设置复用 `FloatingPanel`，统一半透明、backdrop blur、圆角和 0.5px border，可选箭头与箭头位置；此处的底部箭头指向相机按钮。
- 绘制和直接编辑手柄优先消费自己的输入；位移、旋转、缩放工具的 gizmo 操作优先，但非 gizmo 区域的左键/右键拖拽仍用于相机环绕。
- 粗箭头是直接编辑入口：点击面/边/草图只选择，点击或拖动箭头才进入对应几何操作；长度输入位于箭头侧面，不覆盖手柄。面推拉提交后保留当前面锚点、箭头和输入，可立即进行下一次拖拽或数值编辑。
- 三维与草图坐标球以 5px 点击容差区分点击和拖动，只接管实际 128px 显示区域；`pointerup`、`pointercancel`、按钮已松开和窗口失焦都必须清理手势，禁止松手后继续环绕。点击 X/Y/Z 或 U/V/N 球体切换到对应有符号轴向，点击区域空白不切视角。
- 3D/草图右下角坐标轴双击恢复默认视图：3D 使用斜上方透视，草图使用上 V、右 U 的正交正视；目标固定为世界原点或平面原点并适配全部内容，不改成包围盒中心。
- 草图只有 N 球可点击，U/V 不响应；N 始终恢复上 V、右 U 的标准平面视图，不保留当前 roll。
- 草图测量启动时清空未完成的形状/Line 编辑状态并切换选择工具。每次点击都通过参考匹配和磁吸开关取点；第 n 点只连接 n-1 与 n，旧点和旧连线立即清理，测量结果不写入 document。三维与草图测量中按右键均先退出测量并清除标记，再继续视图环绕。
- 草图与首页共用底部测量、剖视、显示设置、适配视图和比例尺布局，不单独隐藏草图测量按钮。剖视使用 ]｜[ 图标，禁用时 tooltip 仍只显示“剖视图”；进入草图时立即退出剖视并禁用按钮，退出草图后保持非剖视。剖视通过逐实体 stencil 正反面计数与剖切平面封口显示实心断面，内部空腔不填端盖；原始表面在真实剖切平面内侧做微量裁剪，cap 不偏移，避免共面底面重复且保持真实断面，且不参与拾取、拓扑或导出。
- 进入编辑前已隐藏的草图或所在平面，编辑期间临时显示，退出后恢复原隐藏状态；进入时可见的草图保留用户在编辑中的显隐操作，不得强制重置。
- 直接编辑工具激活时，非箭头区域的左键拖拽仍用于相机环绕；草图编辑期间不显示拉伸粗箭头。
- 多选 Body 的 Boolean 入口位于 Transform 工具组下方。Transform 工具仅在选中元素时出现，Boolean 仅在可操作时显示，3D 与草图统一使用左滑淡入/反向收起动效。右侧单选详情不显示名称、坐标、Move/Rotate/Scale 快捷入口或更多工具，多选不显示详情面板。
- Boolean 草稿只保留临时 `operation / operandIds / regionSigns`；完成前不得把结果实体插入 document。`buildBooleanRegions` 按 Venn 成员关系拆分独立区域，例如 A-B/AB/B-A，完成时只合并 + 区域。并集全 +，差集仅主模型非交集区默认 +，交集仅全成员交集区默认 +。所有区域统一紫色 +、深红 -，不再叠加原模型。

## 草图图片与 SVG 资产

- 草图编辑中可直接向渲染区 drop 位图或 SVG。位图以 data URL 保存为独立 `image` 实体，点击整图选择，不参与封闭面、拉伸、布尔或实体统计。
- 图片与 SVG 文件夹选中时显示四角、顶部宽度输入和右侧 90° 高度输入；约束区只显示资产比例锁与磁吸。比例默认锁定，尺寸输入以中心缩放，角点拖动固定对角点；解锁后两轴独立。
- 图片四角和 SVG 原始 viewBox 四角都进入参考点体系。SVG 文件夹拖动时排除文件夹及全部子元素自参考。资产拖拽先按原始指针计算真实控制点，再对该控制点磁吸；比例锁定时沿宽高比约束选择最近的单轴参考，禁止先磁吸鼠标导致角点二次偏移。
- 图片渲染顺序始终低于普通形状；图片之间按 document/实体树顺序递增，后面的图片先绘制在上层但不越过形状。
- SVG 按当前正交视图可用范围适配整个 viewBox。rect/circle/ellipse/line/polyline/polygon 转为对应草图，path 采样为可编辑开放线或闭合轮廓；多元素放入 SVG 文件夹，单元素直接生成普通草图。文件夹整体缩放同步变换子元素语义点、曲线控制柄与 parts，非等比缩放会把圆转换为椭圆。

## 边圆角与倒角

- 未处理的直线凸边和至少三个相邻面的角点可建立 treatment。选择状态及两种工具下均显示粗箭头和距离输入；内拖为正圆角、外拖为负倒角，输入使用同一有符号绝对值，新 treatment ID 冻结到实际锚点。曲线边不开放该手势。
- `edgeTreatments` / `vertexTreatments` 保存原始 body-local 几何、相邻面法向、类型和尺寸；末端重放前边处理按当前基础拓扑重定位，角点处理固定排在邻接边处理之后，烘焙基体不会重复应用切削。
- 存在非零角修正时，面、边、角的显示和 CSS 像素热区统一来自最终拓扑。边 Chamfer/Fillet 裁掉的源边不得保留隐形热区；Vertex Rounding 例外，基础代理只开放当前圆角原顶点及三条未做边处理的入射边，用于选择完整原几何和继续编辑。原角热区优先于入射边，其他入射边位置优先于同体圆角面；代理忽略同体遮挡，但其他 Body 仍正常遮挡。
- 倒角/圆角生成面拥有自己的 hover、选中 active 和编辑入口，并优先于附近边界热区。倒角箭头使用生成平面中心和法线；圆角箭头使用被点击曲面的实际三角形中心和法线。拖拽或输入继续修改同一个 treatment，不得转成新实体推拉。
- 边处理的原边在角修正生效后不再显示箭头或 active；圆角原角通过限定代理保留箭头和 active，入射原边可继续建立边 treatment。普通最终边/角不得因距离接近而继承附近 treatment。详情面板提供“复原倒角/圆角”，将当前 treatment 的尺寸设为 0。
- 局部角倒角优先使用 Manifold `trimByPlane` 的负法线半空间裁剪，Chamfer 逻辑保持独立。Vertex Rounding 使用 `VertexRoundingGeometry` 构造外凸四次三角 Bézier 切削面：三张原平面上的边界为圆弧，内侧控制行保持相切，入射棱边在距顶点 `radius` 处终止，不生成凹槽、Chamfer 平面带或圆柱过渡。中心比例固定为 `0.87r`；对称剖面 101 点采样在 `0.86r` 仍有 6 个内凹区间，`0.87r` 为 0，是兼顾外凸与有效切削体积的最低比例，不得仅按外观随意下调。其他角点必须保持原样，已有边 Chamfer 仍在角处理前保留。最终连续曲面提供 active，相邻平面保持独立；棱边终止奇点需拆分渲染法线，同时保留 merge vectors，禁止跨锐边平均造成大平面三角明暗。正方体 8 个角、半径 3/8、外凸中心、平面法线、闭合实体及生成面选择均有 spec 回归。

## 项目 YAML 与存储

- 项目导入、导出和 IndexedDB 统一使用 `utils/projectYaml.ts`；导出扩展名 `.model.yaml`，不再读取旧 JSON。完整紧凑 YAML 方言、单元素数组与精度规则见 `docs/PROJECT_YAML.md`。
- IndexedDB 数据库名为 `lab:model3d`，`projects` store 保存 `{ id, yaml }`，其中 YAML 对应完整 `ProjectRecord`。当前项目 localStorage key 为 `lab:model3d:project:activeId`；不得改回无页面隔离的裸名。
- 数值最多保留 4 位小数，字符串值必须双引号，一维数组无方括号直接逗号分隔，多维数组逐行使用 `-`。格式面向 LLM 时优先保持可读性，不使用 gzip/Base64 作为默认文本。

## 构造平面

- 点击构造按钮立即创建并选中草图平面，不只打开菜单。
- 无参考选择时默认创建原点 XZ 平面。
- 已选构造平面时，以其原点、法向和局部 U/V 轴创建同位置、同方向的新平面。
- 已选实体平面时，以该面的中心点和法向创建参考平面。
- 隐藏平面会隐藏其草图；拉伸完成后保留已使用的草图与所在平面。

## 草图与直接几何编辑

- 3D 封闭草图单击只选择命中的独立面，不进入边/角选择，也不默认选中整个形状；只有 Ctrl/Command + 单击才累加面。命中后必须保存 `profileFace` 并将 `selectionKind` 设为 `face`，无封闭面的开放线不在 3D 中选择。图片仍按整体选择。拖动双向粗箭头才实体化，单向拉伸固定草图底面。由开放线闭合区域直接生成的 body 没有独立 profile 对象，箭头基准必须从实体包围盒中心扣除单侧深度的一半，再加完整深度定位到顶面，禁止重复计入深度。
- active 几何不得只保存点击时的静态世界坐标。`GeometryAnchor` 在视口层保存 owner 与矩阵快照，Transform 拖动时逐帧应用最新矩阵 delta；SceneSynchronizer 重建后按 face ID、sourceIds 和带符号面法向重绑当前拓扑，粗箭头推拉与数值输入都走同一路径。`generatedTreatment` 不受 anchor.type 限制，倒角面（edge）和圆角面（vertex）必须同时重绑；本次几何求解使用的 resolved treatments 随 mesh 发布，面推拉后的圆角选择和 active 不得再读旧角点。Three.js 对象只存在于视口交互层，不进入 Vue 响应式状态。草图编辑 active 面继续由 `SketchRenderer.refreshFaces()` 按最新 profile 每次重建。
- 只有真实圆角曲面映射为原角，不得把整个半径区域都当成圆角，普通相邻平面仍独立选择。其他角点优先于既有圆角面；圆角 hover 必须渲染自身曲面。4px 原边优先区仅用于真正的入射原边。
- 边圆角半径上限保持截面最小尺寸的 1/2；边倒角独立放宽到截面最小尺寸，40mm 立方体单边倒角必须能形成体积 32000 的闭合直角三棱柱。角点处理沿用安全上限，数值输入与拖拽共用同一组正负限幅。
- 草图创建后保持选中，显示操作点和长度输入；Esc/右键取消当前路径或选择。形状切换后的 300ms 内拦截操作点输入，避免旧指针事件修改新形状。
- “线条 / 曲线”对应 `polygon` 开放轮廓；其拖拽与独立 `line` 完成时都复用两次点击的第二点写回路径，右键取消编辑态必须保留已创建实体。
- 形状切换保护必须同时覆盖 pointerdown、pointermove、pointerup；本次选择对应的 pointerup 即使在 300ms 后到达也只消费，不追加点。
- 草图空白左键拖拽保留绘制图形；平面旋转只通过右下角平面坐标球或右键拖拽。空格平移期间屏蔽所有草图编辑事件。
- 草图重连先按解析交点分割全部被穿过的边，再从 1 度端点提取开放链、从剩余图提取闭环，确保曲线端点位于其他边内部时仍可形成封闭轮廓。
- 草图边线使用 Line2 屏幕像素加粗黑线，只在草图编辑模式中为选中与未选中轮廓生成；非草图模式不生成 border，操作点只在当前绘制或选中编辑的形状上显示。
- 草图编辑只显示当前平面及其草图内容，隐藏其他 Body 和其他平面的草图；不显示形状填充色，未封闭轮廓不得进入实体拉伸。
- 进入/退出草图使用约 600ms 的相机与背景透明度过渡，退出恢复进入前视角；封闭区域使用 shader 平行线填充，不做逐像素或逐边线计算。
- 相机过渡使用四元数插值，正交返回透视时按 orthoHeight 匹配起始尺度，避免投影跳变；删除当前草图平面必须先退出编辑。
- 封闭区域使用透明绿底＋平面 UV shader 平行线，纹理跟随世界坐标和所在平面方向，不跟随视角；绘制工具活跃时不对其他封闭形状施加 hover active。
- 草图提供独立“选择”工具：有形状时默认选择，无形状时默认 Line。绘制工具激活时点击其他轮廓只作为当前工具输入，不切换选择。
- border 删除后按端点连接关系检测闭环；度数为 2 且至少两条边的连续边组重新合并为封闭 Profile，圆/椭圆开放弧也参与重闭合，无法闭合的段继续保持开放。
- 草图编辑时，当前平面的形状作为实体树子节点展示，并平滑滚动到该平面；退出编辑即移除子树。未选中时底部对象数与三角形数只统计独立 Body，排除平面和草图；选中后切换为当前选择的统计。
- Alt/Option＋hover border 时按交点区间标红，点击只删除该区间。无交点时删除完整 border；有交点时按端点/交点分段。
- 删除普通边后转换为独立开放段；贝塞尔使用 de Casteljau 保留控制点，圆/椭圆用 `open + profileStartAngle + sectorAngle` 保留圆心和半径参数。已有拉伸引用的草图不得静默破坏。
- 圆、椭圆、圆弧和贝塞尔使用解析曲线作为逻辑 border；求交、最近点和裁剪基于曲线参数，采样仅用于 Three.js 显示，不按采样切线角度拆分曲线。
- 贝塞尔控制柄使用所在边的归一化局部坐标；所有端点运动与约束传播必须通过 `rebaseCubicCurve` 同步控制柄，只有直接手柄编辑可改变相对曲率。解析与 legacy curves 必须同步写回。
- border 求交必须包含 T 型的端点-边相交，不能只接受边-边内部交叉；重连后的近端点使用 0.02 模型单位容差，圆周跨 0°/360° 区间按环绕弧切片，禁止读取负索引；选中形状的 handler、辅助线使用最高渲染层，禁止被其他轮廓覆盖。
- 椭圆使用两个带方向的正交半径向量，拖动任一半径点时另一个保持原半径并同步旋转，扇形点与裁边统一使用椭圆局部参数角；控制点拖动期间不重建完整场景。
- 圆/椭圆扇形点拖动吸附整数角度，90° 倍数附近有增强磁吸；双击恢复完整圆/椭圆。非 360° 扇形在逻辑拓扑中拆成起始半径、解析圆弧、结束半径三条边，封闭面由此闭合；Alt 删除和交叉裁剪按独立边处理，删除半径不得连带删除圆弧。双击贝塞尔控制点将其放回直线，拖动端点不改变原本直线段的曲率。
- 草图参考线计算独立放在 `engine/sketchGuides.ts`，视口叠加层与草图几何分离；矩形/正多边形及圆/椭圆中心均进入参考点，重叠但未 trimmed 的标准形状仍允许整选。不为参考高亮修改原轮廓材质，清空叠加层即恢复显示。
- 单点使用所有参考点的同轴水平/垂直线；形成 Line 边时增加所有真实直线的平行/垂直线。水平与垂直匹配同时进入阈值时必须吸附到交点并显示两条参考线，不得再全局只取一条。磁吸阈值使用屏幕像素，禁止直接以固定世界距离判断。
- 约束区磁吸开关默认开启；关闭只禁用坐标吸附，不得禁用参考线匹配、显示或参考对象高亮。
- 参考匹配和参考线显示仅在按下绘制或拖动时启用，普通悬停必须清空参考叠加层。撤销/重做先取消 `sketchDrag` 与 `shapeDrag`、清空草稿并消费剩余 pointerup，禁止旧预览在撤销后重新写回实体。
- 标尺主/中/短刻度按 10 等分显示且不参与吸附；参考线拖动只使用操作点、参考线和交点磁吸。参考线 hover 按方向显示 col-resize/row-resize；绘制工具活跃时已有参考线不接收点击，画布创建形状优先，仅选择工具允许抓取参考线；选择工具下按操作点/控制柄与草图边 > 参考线处理重叠热区，操作点周围 12px 镂空，草图边按 8px 屏幕阈值优先。参考线位置输入使用独立绿色底，移到标尺内侧 18px，左侧与刻度文字同为 rotate(-90°)。拖回标尺或拖出对应视口边界视同删除，新参考线立即拖回不留下空撤销。
- 约束创建时的局部求解放在 `engine/sketchConstraints.ts`，持久规则统一由 `engine/sketchConstraintSolver.ts` 全局求解；必须先验证完整结果再写入 App 状态，禁止逐边直接修改共享顶点。固定点不可移动，冲突或封闭轮廓退化时保留原草图。
- 标准封闭形状（`standardShape` 标记的矩形/正多边形及圆/椭圆）填充区 hover 显示 grab，单击选择整形，拖动执行整体平移。拖动预览统一用草稿点重算封闭面，标准形状中心也从草稿点计算并立即跟随，结束后才由 document 接管。整体磁吸分别尝试所有语义点、计算中心点和贝塞尔控制柄，以最小修正量移动整形并排除自身；标准形状中心注册为其他操作的参考点，裁剪/拆解后移除中心控制点及参考注册。任意封闭 polygon、裁剪面和复合区域保持原交互。
- 点与边选择互斥；固定边等于固定其所有端点，含固定点的形状禁止通过中心抓手整体移动。Line/Polygon 的逻辑边即使已转成贝塞尔弧，方向、平行、垂直、等长和固定长度也只使用两个语义端点构成的弦，贝塞尔控制柄不参与求解且不得被约束重置；独立三点 Arc 的中间点不是端点，不走该规则。
- 矩形和正多边形只在绘制预览阶段保留工具语义，创建完成立即转为 `polygon` 共享端点边和普通 `edgeConstraints`：矩形写邻边正交，正多边形写各边与首边等长及邻边有向夹角（外角 `360° / 边数`）；仅有等边不足以保证正多边形。后续点拖、边尺寸、曲线编辑和约束传播不得恢复中心/半径或专属形状求解。
- 约束求解不再固定第一条参考边，也不显示绿色参考边。每次操作按“当前选择点不动 > 当前选择边两端不动 > 整条约束链自由调整”逐级尝试；较低优先级只在高优先级无解时启用，显式固定点始终不可移动。
- 草图视口上、左显示 12px 标尺，刻度 0 与平面局部原点一致，数字放在刻度线侧方。顶部拖出水平参考线、左侧拖出垂直参考线；参考线以 `SketchPlane.guides` 持久化，使用虚线长期展示但不进入轮廓、封闭面或拉伸。参考线可选中拖动、按 Delete 删除，标尺处提供红底白 ×；数值输入使用独立绿色底并内移 18px（左侧 rotate(-90°)）；对应 U/V 轴进入普通参考匹配。拖动参考线时始终匹配最近主刻度值（短刻度仅显示）和草图参考点，排除自身并取最近候选，均受磁吸开关控制。
- 当前规则面板必须列出所选元素的全部固定与边规则，每行提供独立红底白 X 删除按钮；固定与几何规则使用各自删除逻辑，不得只显示最后点击的锁。
- 边锁与尺寸按 `entityId + 边索引` 配对：同一边有尺寸输入时，锁作为尺寸控件内的独立按钮排在单位后，禁止再用绝对定位互相覆盖；没有尺寸的边锁居中于边中点，多规则按固定屏幕间距排列。缩放只更新世界锚点投影，不得累计额外偏移。
- 方向约束按钮按当前选中边的实际规则显示应用状态，H/V/水平/垂直生效时使用 active 色和粗体，不以临时点击状态代替。
- 固定长度是多选边各自持有的独立规则，保存应用时的边长；端点拖动投影到对应圆周，两个相邻固定长度约束取圆周交点。
- 约束链由 `sketchConstraintChain` 生成整形状、关联端点、非关联点和单次要顶点候选，比较所有可行解并按额外移动顶点数选优，平票保留更强锚点；尺寸写回额外传入精确目标向量。所有方案无解或传播超限时恢复整个操作前的几何并提示。
- 逻辑边内部使用局部端点索引，选中反馈、固定点和约束锚点必须先映射为实体顶点索引；矩形/正多边形等长关联边通过同一联合求解器调整，禁止再使用单独角点或圆心/半径重建算法。
- 非 Line 形状提供中心操作点，拖动中心只平移整个形状及其曲线控制点，不改变尺寸。
- Line 操作点支持 Alt/Option＋点击删除；至少保留两个点，删除后同步重排曲线与锁定点索引。
- 当前选中形状统一使用 active 颜色；操作点带描边，抓手/删除光标与边框 hover、选中深色必须明确区分。
- 长度输入的 blur 写回延迟到事件结束后执行，避免 Vue 覆盖层在 blur 中同步重建导致输入焦点和节点状态异常。
- 长度输入使用两位小数和 mm/cm/m；项目几何数值视为无单位，切换单位不得修改数值，单位只用于展示和导出语义。
- 长度/角度输入的 step 使用整数，小数值先按操作方向取整再步进；未 hover/focus 时透明度为 50%。
- 所有 number input / NInputNumber 都必须支持滚轮增减，并阻止滚轮冒泡到画布造成视图缩放；步进遵循控件 step，长度和角度继续沿用整数取整规则，禁用状态不得响应。
- 颜色统一从 `colors.ts` 的色表读取；hover/选中使用透明橙色系列。
- 面拉伸使用独立的 `faceOffset` 预览参数；正位移对 owner body 执行 Union，负位移执行 Subtract，松开后烘焙为当前 `meshGeometry`。
- 粗箭头以手势起始面为基准按绝对 delta 平移，世界拖拽距离按固定屏幕投影计算并转换到局部实体缩放；不得逐帧累加 preview。旧箭头命中时若几何锚点已清空必须忽略启动并刷新 guide，禁止读取空锚点 vertices；连续二次拖动不得依赖尺寸输入 blur。
- 粗箭头使用天蓝色，hover 使用深蓝色，拖动使用绿色，描边固定为黑色；箭头只绘制整体外形轮廓，不使用三角化几何的 `EdgesGeometry`。
- 面选择由 `MeshTopology` 按共享边和 SameDomain 计算，高亮参与深度测试并使用 polygon offset；背面不得透画到其他面。
- 轮廓显示与拾取共享 logical edge graph，三角剖分边和周期 seam 不成为独立模型边。
- 倒角/圆角交互与 `edgeTreatments` 数据契约统一遵循上文“边圆角与倒角”章节，不再保留已移除能力的旧约定。

## 数据与存储

- 浏览器存储继续遵循 `lab:model3d:*` 前缀；不得清理其他页面数据。
- 用户明确宣布“正式完工”之前，修改项目数据结构不需要保持旧项目可读，也不新增迁移或回退逻辑。
- 平面或草图删除必须检查 Extrude/Boolean 依赖；右键删除和 Delete/Backspace 共用同一逻辑。

## 本轮草图维护约定

- 参考匹配必须排除整个当前形状，不允许点或边自参考；其他矩形的中心纳入参考点。
- `SketchRegionPreview` 为开放 line 组成的闭合区域生成视口专用填充面，退出草图后仍显示并携带区域轮廓用于点击/拉伸；预览不进入 buildScene、实体树或导出，重新进入草图时由普通 SketchRenderer 面接管。
- 拆分后的开放 line 若在所在平面组成唯一闭合区域，任一组成线都可显示拉伸箭头并发起区域拉伸。区域 body 必须强制 `open=false`，使用区域自身有序采样轮廓并清空来源单线的 curves/analyticCurves，禁止把被点击线的曲线索引套到区域其他边上。开放线普通点击只选择，不建立实体面锚点；失效 triangle-face 映射退回当前三角形，不得抛出 `triangleIds` 空引用。
- 尺寸输入 Enter 与 blur 均可写回；退出草图必须清空 face 选择和几何锚点。
- 控制点拖动期间不得同步写回响应式 document；只在 pointerup 写回并同步场景，避免深度 watch 和自动保存拖慢预览。
- 裁边使用 `sketchRestitch.ts` 统一重连：先合并连续开放链，再提取闭环；`sliceBorder` 必须去除重复端点，零长度边不得进入图。平滑圆弧采样属于同一逻辑 border，不能拆成独立草图实体。
- 圆/椭圆 border 求交和区间必须支持采样顶点与跨 0° 区间；不得按线性 0..1 区间处理圆周接缝。
- 重连路径必须维护 `controlPoints`，采样点只参与几何显示，不生成手柄、尺寸输入或参考线。
- 草图右键和坐标球只允许平面 roll，旋转量必须来自指针绕平面原点/坐标球中心的真实夹角，禁止用 3D 轨道或横向像素差近似；三维右键、坐标球及退出草图后必须保持世界 Y 轴向上。
- 封闭面统一由 `sketchFaces.ts` 计算并在每次写回后刷新；不得在多个模块分别用 open 推断视觉封闭区域。面渲染层级必须低于 border/操作点，面点击不得触发形状选择。
- 贝塞尔编辑草稿只使用两个语义端点，65 个渲染采样点仅供显示，禁止把前两个采样点写成端点。
- 已裁剪实体使用 `trimmed` 区分逻辑边编辑：直线端点编辑保持共线并同步更新 `curves`/`analyticCurves`，控制柄固定于 1/3、2/3 位置；控制柄拖动保留非共线曲线且重新选中不消失，两种行为均有 spec；连续曲线端点拖动整体平移；未裁剪实体保持整形状编辑。

## 颜色与填充调整

- `config/colors.ts` 是唯一的三维颜色区：`SKETCH_COLORS` 管草图和操作点，`VIEWPORT_COLORS` 管背景、灯光、实体选中与测量，`AXIS_COLORS` 统一三维与草图坐标轴、测量轴和 TransformControls 移动/旋转/缩放坐标，`GIZMO_COLORS` 引用同一色值并管正负轴端点，`ENTITY_COLORS` 管新实体默认色。X/Y/Z 使用协调且可区分的中等饱和红/绿/蓝，负轴与正轴同色、降低不透明度。
- 界面颜色也在同一文件：`UI_COLORS` 对应 `var(--model3d-ui-<hex>)`，`UI_NAMED_COLORS` 对应 `var(--model3d-ui-<name>)`，由 `index.ts` 在挂载前注入。调整色值只改 const，不在 Vue/CSS 中新增硬编码颜色。
- 平行线颜色使用 `SKETCH_COLORS.line`；线宽、间距和不透明度在 `config/const.ts` 的 `SKETCH_STYLE.hatchLineWidth / hatchSpacing / hatchOpacity` 调整，单位与草图平面坐标一致。
- 扇形磁吸阈值在 `INTERACTION.sectorQuarterSnapThresholdDeg` 调整；默认在 90° 倍数前后 4° 内吸附。
- 草图参考线及参考对象使用 `SKETCH_COLORS.reference`（参考色）；统一屏幕磁吸距离在 `INTERACTION.sketchGuideSnapPx` 调整，默认 8px。

## 草图高级工具与复合形状

- 对称使用独立二维临时画布，禁止把临时副本或不同 id 的复制实体写入 document；退出不得改动源草图，完成只新增一个含 `parts` 的草图实体。
- 扇区以正上方为 0°、顺时针增加。裁剪必须使用两条无限分界线，轴对称采用相邻扇区镜像，旋转对称采用顺时针旋转；奇数扇区无法满足每条分界线均为镜面，必须强制旋转对称并禁用轴对称选项，若支持奇数轴对称需改用 2N 基本扇区。相关边界修改必须更新 `sketchAdvanced.spec.ts`。
- 草图平移/旋转/缩放不得调用三维 `TransformControls`，也不得退出草图。二维手柄与输入直接修改语义点或 `parts`，支持工具优先和形状优先两种选择顺序。
- 约束求解使用 `sketchConstraintSolver` 全局联合求解，矩形正交及 H/V、平行/垂直、固定长度和多条 line 的关联在同一方程组内收敛。创建约束时固定第一条参考边；后续尺寸操作以 `sketchDimension` 产生的目标长度、方向和锚点为精确条件，关联另一方可以反向调整。固定点、当前操作点、关联端点和形状其余点仍按候选优先级处理。达到容差立即停止，冲突回滚到操作前，重复求解/blur 不得产生漂移。
- 所有磁吸以真实操作点为目标，鼠标只负责定位手柄。单点以该点为目标，多选/形状平移以选中内容中心为目标，线段方向以另一个端点为锚点。参考优先级为精确点/原点、方向参考、单轴交点；平行/垂直使用正在拖动的线段和其他真实线段，禁止用鼠标偏移代替操作点。

## 类型检查与提交钩子

- `tsconfig.model3d.json` 启用 `noUncheckedIndexedAccess`，提交前必须通过 `yarn typecheck:model3d`。不得用 `strict: false` 或跳过检查掩盖空数组、空引用等错误。
- 仓库使用 `scripts/git-hooks/pre-commit`，本地通过 `git config core.hooksPath scripts/git-hooks` 启用；钩子只执行 model3d 类型检查，避免全仓历史类型问题阻塞页面迭代。
- 变换手势必须保存初始指针、轮廓、语义点和曲线控制点，每帧以初始快照和当前指针差值计算；不得逐帧累加相对 offset。平移手柄跟随形状，旋转手柄跟随角度，普通草图草稿同步消除旧位置残影。
- 高级编辑画布激活时暂停普通 ViewportOverlay，避免旧尺寸输入遮挡手柄；滚轮和右键二维旋转必须转发到原视图控制。
- 旋转/缩放中心及临时圆形中心拖动必须复用 `matchSketchGuide` 和 `sketchGuideSnapEnabled`，保留自身语义角点，支持平面/世界原点与其他草图参考点；开关关闭时不得吸附。变换输入复用 `sketch-length-input`，长度带单位选择、角度为 deg、缩放为 x，位置不得覆盖对应手柄。
- 对称第三步的选择工具必须提供临时形状整体移动和控制点编辑。`SketchProfilePart.editor` 只保存临时语义点，圆/椭圆/正多边形不得把渲染采样点暴露为控制点；完成裁剪后的复合 `parts` 不保留该编辑元数据。
- `parts` 是同一草图实体的多个独立轮廓，border、面、显示、拉伸和选择逻辑必须保持实体级聚合；不得退化为多个临时 Items。

## 实体拓扑与直接编辑

- 实体几何内核使用 `manifold-3d` WASM，页面挂载前完成初始化。Three.js 只负责渲染和交互；WASM 输出数组必须复制，Manifold 对象显式 `delete()`。
- `engine/topology/` 独立维护 render vertex、topological vertex、half-edge 邻接、logical face 和 logical edge。`faceIndex` 与显示线段序号只允许用于当次命中，不得作为持久身份。
- 默认面选择是同一 body 内、共享边连通的 SameDomain patch；不合并不连通共面岛或点接触面。解析圆柱/球面优先使用 surface metadata，其他 mesh 曲面只提供 smooth patch 近似。
- 显示边和拾取边来自同一个 logical edge graph。三角剖分边、共面分割边和周期 seam 不进入可选边；细分直线和圆弧由度数、切向和邻面关系合并。
- 边拾取使用 CSS 像素阈值，默认进行遮挡过滤；“穿透选择”是显式开关。面/边的“相切扩选”也是显式开关，不能改变默认 SameDomain 语义。
- 非平面实体面的推拉入口必须禁用，不显示粗箭头；曲面 Offset 需要独立实现。实体平面直接编辑只声明 Face Extrude：从手势开始时的 S0/F0/n0 构造闭合扫掠体，正位移 Union、负位移 Subtract，仅修改 owner body。切穿可返回空实体，禁止反向生成新实体。
- `DirectEditTransaction` 固定 baseEntity、baseRevision、gestureId 和递增 sequence；每次 preview 都从 S0 计算。pointerup 重新计算最终参数，cancel/Esc/失焦恢复 S0，失败不提交坏模型。
- 世界拖拽距离转换到实体局部距离时考虑缩放；UI 始终显示世界单位。烘焙结果同时保存 position/index 与内核 merge vectors，normal/UV seam 对应的 render vertices 不得直接当作拓扑顶点。
- `GeometryValidator` 在提交前检查 finite、索引、属性版本、groups/drawRange、定向共享边、闭合性、体积和 components；合法小三角面不能靠放大 epsilon 删除。

- Face Extrude 工具体先由真实外环/孔环重新三角化 cap，不继承 Boolean 面内部碎边。工具体向 S0 内穿透使用 `min(0.001, |d| / 2)` 的几何重叠用于避免曲边共面接触；它不是逐步放大的误差公差，最终 cap 仍精确位于 d。
- Extrude/Boolean 完成时通过 `bakeEntityGeometry` 保存独立网格。`profileId / operands` 只用于显式 History 回改，不再参与已提交模型的日常重建。
- 删除源草图或源实体时由 `detachFeatureReferences` 先确保结果已烘焙，再移除失效的 History 引用；不得因为源对象被删除而阻止操作或破坏结果。

- 3D 草图材质创建时保存真实 `sketchBaseOpacity`；编辑态临时透明化不得成为 hover 离开后的恢复值。hover 只改变颜色/临时透明度，不负责草图可见性。
- 实体默认使用中性灰色、无贴图、无金属的粗糙材质；不得加载 RoomEnvironment 或其他环境贴图。Boolean 输出使用 `calculateNormals(0, 60)` 在锐边拆分法线，禁止用跨锐边平均的 smooth vertex normal 制造平面云纹。
- Boolean 输入先执行 Manifold `simplify()`；输出必须先 `asOriginal()` 合并同域关系，再 `simplify()` 清理三角化。顺序不得反转，也不需要 mouseup 后延迟；`faceEdit` 只允许在相邻 revision 间映射被拖动的平面，禁止对任意平行面猜测绑定。

- Boolean preview 与提交烘焙必须共享 normals、merge vectors 和 sourceFaceIDs；放手后不得重新 `computeVertexNormals()`。旧烘焙数据缺少 normals 时由 `normalizeBakedGeometryNormals` 经 Manifold 恢复，禁止用自定义拆点改变建模输入。
- 接缝平面 cap 使用 Manifold `triangulate(polygons, 1e-9, false)`，支持孔洞和共线边界；Three.js ShapeUtils 的退化 cap 不得进入工具体。烘焙发布前再次执行完整实体校验。
- Logical edge 同时保存无序拾取 segments 和有序 points；`EdgePicker` 返回的 index 就是原始顶点下标，不得再次乘 2。圆弧 hover/选中使用 points 连续路径，Select Through 下每条边都应能命中自身。
### Face Extrude 提交顺序（不可调整）

1. 固定手势的 S0/F0/n0、body revision；每次 preview 均从同一个 S0 求值。
2. Boolean 输入先分别 `simplify()`，再执行 owner body 的 Union/Subtract。
3. 输出先 `asOriginal()` 合并同域关系，再 `simplify()` 清理三角化；顺序不可反转。
4. 使用 `calculateNormals(0, 60)` 生成锐边法线。
5. 校验有限坐标、索引、定向共享边、闭合性、体积和 components。
6. 一次性保存 positions、indices、normals、merge vectors、sourceFaceIDs，并递增 revision。
7. 由同一次场景同步重建 render geometry、拓扑、显示边与 picking 数据。

禁止在 mouseup 后 sleep 或等待下一次拖拽来补合并。preview 与 committed mesh 只能有 revision/事务状态差异，不得有几何、法线或拓扑差异；`same-domain faces are merged before release simplification` 和 `release preserves the exact preview geometry...` 两项 spec 必须同时通过。

- 通用 Offset Face、Move Face 不属于已支持能力。Chamfer/Fillet 仅限上文直线凸边和三面角点的参数化实现，不得以 smooth normal 或网格雕刻冒充其他曲面处理。

- 草图尺寸组合契约以 `docs/SKETCH_EDITING.md` 的 22 个 case 和 `engine/sketchDimension.spec.ts` 为准；修改尺寸或约束必须同步两者。

## 3D Shell 与多面选择

- `engine/modeling/Shell.ts` 负责均匀内缩与开口切割；开口柱体保留所选面的世界/局部转换后的完整边界，起切深度等于壁厚，禁止伸入相邻保留壁。
- `useShellOperations` 使用 `shallowRef` 保存 session，确保 OperationBar 的 `shellActive` 响应开始/取消；操作前实体与开口锚点随 session 保存，壁厚变化从原实体重算并只写入 `ShellPreviewController`；预览阶段不改 document、不保存、不写 history，完成时才烘焙为 `meshGeometry` 并产生一步撤销，不叠加 parametric edge treatments。
- `InteractionController.geometryAnchors` 保存多面选择，`GuideRenderer` 对每个面渲染 active feedback。Ctrl/Command 重复选择同一面只切换该面，App 不再通过 body id 的 toggle 处理这种多选。
- `ShellOperationBar.vue` 提供厚度输入、完成和取消；Shell 不使用指针旁 `directFace` 尺寸输入。剖视封口同时采集提交实体与 Shell 预览网格，cap 不读写深度并使用高对比壁面材质，避免内表面遮挡截面壁。

## 草图几何约束与变换中心

- 单个带语义中心的形状进入 Rotate/Scale 时，`sketchTransformCenter` 优先采用 `standardShapeCenter`；多选或无中心形状仍使用组合包围盒中心，用户拖动中心后保持新中心。
- `sketchGeometricConstraints.ts` 统一描述直线、圆和椭圆约束几何。相切支持直线—圆/椭圆及曲线间关系，同心支持圆、椭圆、标准矩形和正多边形；规则保存在现有 `edgeConstraints`，进入同一 Gauss-Newton 关联链、固定点保护、删除、高亮与撤销。
- 曲线相切使用法向支撑半径计算残差，圆/椭圆的中心、半径点和方向点均参与数值求导；不得退化为点击时一次性移动。`tangentMode` 记录创建时的内切/外切关系。
- 约束面板按方向、几何关系和固定分区使用三列网格；全部规则独立滚动，列表使用 `scrollbar-gutter: stable`、右侧 padding 和固定删除列，滚动条不得覆盖删除按钮。
