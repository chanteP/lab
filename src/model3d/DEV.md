# model3d 开发要求

本文件记录 model3d 的通用交互与交付约定。新增或调整功能时同步更新本文件和 `INTERACTIONS.md`，并遵守仓库根目录的 `AGENTS.md`。

草图编辑的独立交互契约维护在 `docs/SKETCH_EDITING.md`；修改草图行为时必须同时更新该文档。

## 方案变更与回归

- 任何交互、几何表示、求交、裁剪、重连或约束方案变更，必须在同一提交同步更新 `DEV.md`、`INTERACTIONS.md`、`docs/SKETCH_EDITING.md` 和 `docs/REFACTOR.md` changelog；文档与实现不一致视为未完成。
- 已踩过的边界条件和历史坑点必须同时留下 spec 回归与源码注释，说明触发条件和正确约束，禁止只靠临时浏览器验证或下次重新调参。
- model3d spec 使用 Node 原生 test，通过 `node src/model3d/run-tests.mjs` 执行；解析曲线、交点、圆周接缝、裁剪和重连变更必须先补失败用例，再修改实现。

## 交付

- 只修改 `src/model3d/` 与构建生成的 `docs/model3d/`，不带入其他页面或无关文件。
- 默认不启动本地 serve。完成后执行 `yarn build model3d`，检查变更范围，再 commit、push。
- 构建产物必须是相对资源路径；不手改 `docs/`、页面 `<head>` 或其他页面产物。

## 工具栏与文案

- 可见文案使用简洁中文；单位、格式名和快捷键除外。导出入口统一称“导出”。
- `.tool-group` 中的工具按钮统一为白底、边框、圆形图标按钮，不在按钮外套 Naive UI Tooltip。
- 工具按钮通过 `data-label` 提供名称，hover 时标签向右侧以 translateX 动效展开。
- 移动、旋转、缩放直接放在独立工具分组，分组上下增加间距，不再藏入“变换”二级菜单。
- 菜单项使用图标＋操作名／短说明，不使用整行 hover/active 背景色或大面积白色工具条背景。
- 补充说明优先使用合适位置的 info 图标＋hover，或局部 Tooltip；不在底部重复罗列鼠标操作，不显示坐标系说明。

## 布局与状态反馈

- 顶部项目栏高度 50px。
- 单位放在渲染区右上角；模式徽标可与单位同区展示，不保留空的面板容器。
- 参考尺和坐标系贴近渲染区右下角，当前统一 bottom 12px。
- 渲染统计使用半透明黑色胶囊，放在渲染区左下角；不占满整行。
- 自动保存不展示常驻文案，只在保存期间于项目名旁显示 loading，完成后消失。
- 参考尺的适配按钮只显示“适配视图”，不附加括号说明。

## 相机与选择

- 非工具状态下，普通左键拖拽与右键拖拽一样用于相机环绕；左键单击仍用于选择面、边或轮廓。
- Command/Ctrl＋左键拖拽才进入框选；框选仍区分完全包含与接触相交。
- 空格＋左键拖拽用于平移视图（OrbitControls PAN）。右键保持环绕，中键保持平移，滚轮缩放。
- 参考尺旁提供透视/正交相机切换，默认透视；切换时保留视角与目标点，草图退出后恢复此前投影。
- 位移、旋转、缩放、绘制和直接编辑等工具状态优先消费自己的输入，不把普通拖拽误当成相机操作。
- 粗箭头是直接编辑入口：点击面/边/草图只选择，点击或拖动箭头才进入对应几何操作。
- 直接编辑工具激活时，非箭头区域的左键拖拽仍用于相机环绕；草图编辑期间不显示拉伸粗箭头。

## 构造平面

- 点击构造按钮立即创建并选中草图平面，不只打开菜单。
- 无参考选择时默认创建原点 XZ 平面。
- 已选构造平面时，以其原点、法向和局部 U/V 轴创建同位置、同方向的新平面。
- 已选实体平面时，以该面的中心点和法向创建参考平面。
- 隐藏平面会隐藏其草图；拉伸完成后保留已使用的草图与所在平面。

## 草图与直接几何编辑

- 封闭草图单击只选择，可多选；拖动双向粗箭头才实体化。单向拉伸固定草图底面。
- 草图创建后保持选中，显示操作点和长度输入；Esc/右键取消当前路径或选择。形状切换后的 300ms 内拦截操作点输入，避免旧指针事件修改新形状。
- “线条 / 曲线”对应 `polygon` 开放轮廓；其拖拽与独立 `line` 完成时都复用两次点击的第二点写回路径，右键取消编辑态必须保留已创建实体。
- 形状切换保护必须同时覆盖 pointerdown、pointermove、pointerup；本次选择对应的 pointerup 即使在 300ms 后到达也只消费，不追加点。
- 草图空白左键拖拽保留绘制图形；平面旋转只通过右下角平面坐标球或右键拖拽。空格平移期间屏蔽所有草图编辑事件。
- 草图重连先按解析交点分割全部被穿过的边，再从 1 度端点提取开放链、从剩余图提取闭环，确保曲线端点位于其他边内部时仍可形成封闭轮廓。
- 草图边线使用 Line2 屏幕像素加粗黑线，只在草图编辑模式中为选中与未选中轮廓生成；非草图模式不生成 border，操作点只在当前绘制或选中编辑的形状上显示。
- 草图编辑只显示当前平面及其草图内容，隐藏其他 Body 和其他平面的草图；不显示形状填充色，未封闭轮廓不得进入实体拉伸。
- 进入/退出草图使用约 600ms 的相机与背景透明度过渡，退出恢复进入前视角；封闭区域使用 shader 平行线填充，不做逐像素或逐边线计算。
- 相机过渡使用四元数插值，正交返回透视时按 orthoHeight 匹配起始尺度，避免投影跳变；删除当前草图平面必须先退出编辑。
- 封闭区域使用透明绿底＋平面 UV shader 平行线，纹理跟随世界坐标和所在平面方向，不跟随视角；绘制工具活跃时不对其他封闭形状施加 hover active。
- 草图提供独立“选择”工具：有形状时默认选择，无形状时默认 Line。绘制工具激活时点击其他轮廓只作为当前工具输入，不切换选择。
- border 删除后按端点连接关系检测闭环；度数为 2 且至少两条边的连续边组重新合并为封闭 Profile，圆/椭圆开放弧也参与重闭合，无法闭合的段继续保持开放。
- 草图编辑时，当前平面的形状作为实体树子节点展示，并平滑滚动到该平面；退出编辑即移除子树。底部对象数与三角面数只统计独立 Body，排除平面和草图。
- Alt/Option＋hover border 时按交点区间标红，点击只删除该区间。无交点时删除完整 border；有交点时按端点/交点分段。
- 删除普通边后转换为独立开放段；贝塞尔使用 de Casteljau 保留控制点，圆/椭圆用 `open + profileStartAngle + sectorAngle` 保留圆心和半径参数。已有拉伸引用的草图不得静默破坏。
- 圆、椭圆、圆弧和贝塞尔使用解析曲线作为逻辑 border；求交、最近点和裁剪基于曲线参数，采样仅用于 Three.js 显示，不按采样切线角度拆分曲线。
- border 求交必须包含 T 型的端点-边相交，不能只接受边-边内部交叉；重连后的近端点使用 0.02 模型单位容差，圆周跨 0°/360° 区间按环绕弧切片，禁止读取负索引；选中形状的 handler、辅助线使用最高渲染层，禁止被其他轮廓覆盖。
- 椭圆使用两个带方向的正交半径向量，拖动任一半径点时另一个保持原半径并同步旋转，扇形点与裁边统一使用椭圆局部参数角；控制点拖动期间不重建完整场景。
- 圆/椭圆扇形点拖动吸附整数角度，90° 倍数附近有增强磁吸；双击恢复完整圆/椭圆。双击贝塞尔控制点将其放回直线，拖动端点不改变原本直线段的曲率。
- 草图参考线计算独立放在 `engine/sketchGuides.ts`，视口叠加层与草图几何分离；不为参考高亮修改原轮廓材质，清空叠加层即恢复显示。
- 单点使用所有参考点的同轴水平/垂直线；形成 Line 边时增加所有真实直线的平行/垂直线。水平与垂直匹配同时进入阈值时必须吸附到交点并显示两条参考线，不得再全局只取一条。磁吸阈值使用屏幕像素，禁止直接以固定世界距离判断。
- 约束区磁吸开关默认开启；关闭只禁用坐标吸附，不得禁用参考线匹配、显示或参考对象高亮。
- 参考匹配和参考线显示仅在按下绘制或拖动时启用，普通悬停必须清空参考叠加层。
- 约束求解独立放在 `engine/sketchConstraints.ts`，必须先验证完整结果再写入 App 状态；禁止逐边直接修改共享顶点。固定点不可移动，冲突或封闭轮廓退化时保留原草图。
- 点与边选择互斥；方向、平行、垂直和等长只处理直线。固定边等于固定其所有端点，含固定点的形状禁止通过中心抓手整体移动。
- 当前规则面板必须列出所选元素的全部固定与边规则，每行提供独立红底白 X 删除按钮；固定与几何规则使用各自删除逻辑，不得只显示最后点击的锁。
- 方向约束按钮按当前选中边的实际规则显示应用状态，H/V/水平/垂直生效时使用 active 色和粗体，不以临时点击状态代替。
- 固定长度是多选边各自持有的独立规则，保存应用时的边长；端点拖动投影到对应圆周，两个相邻固定长度约束取圆周交点。
- 约束链按当前操作点、关联端点、所在形状其余顶点的优先级生成候选方案，支持反向调整参考元素；同级按非贝塞尔顶点改动数量选优，所有方案无解或传播超限时恢复整个操作前的几何并提示。
- 逻辑边内部使用局部端点索引，选中反馈、固定点和约束锚点必须先映射为实体顶点索引；矩形等长关联边拖动时以当前边而非固定顶边重建其余角点。
- 非 Line 形状提供中心操作点，拖动中心只平移整个形状及其曲线控制点，不改变尺寸。
- Line 操作点支持 Alt/Option＋点击删除；至少保留两个点，删除后同步重排曲线与锁定点索引。
- 当前选中形状统一使用 active 颜色；操作点带描边，抓手/删除光标与边框 hover、选中深色必须明确区分。
- 长度输入的 blur 写回延迟到事件结束后执行，避免 Vue 覆盖层在 blur 中同步重建导致输入焦点和节点状态异常。
- 长度输入使用两位小数和 mm/cm/m；项目几何数值视为无单位，切换单位不得修改数值，单位只用于展示和导出语义。
- 长度/角度输入的 step 使用整数，小数值先按操作方向取整再步进；未 hover/focus 时透明度为 50%。
- 颜色统一从 `colors.ts` 的色表读取；hover/选中使用透明橙色系列。
- 面拉伸使用独立的 `faceOffset`，只向所选面外侧新增几何，不修改基础 Body 的尺寸、位置和旋转。
- 面偏移支持正负值：正向拼接外侧实体，反向用局部布尔切削从该面向内收缩；粗箭头跟随当前面位置，并按箭头屏幕投影方向计算拖动距离。
- 自动布尔后的 `boolean` 实体也必须支持面偏移，使用其实际几何包围范围生成局部扩展/切削，不得再以实体类型为由拦截。
- 粗箭头使用低饱和蓝，hover/拖动使用橙色，关闭 depthTest/depthWrite 并使用高 renderOrder；箭头几何随场景同步重建时仍保留交互高亮。
- 面选择按相邻面片法向夹角扩展为连续平面/曲面，不只高亮单个三角形。
- 倒角/圆角只切削，不得扩大原实体边界；面/边使用独立高亮，不以整个 Body 变色代替。

## 数据与兼容

- 浏览器存储继续遵循 `lab:model3d:*` 前缀；不得清理其他页面数据。
- 修改项目数据结构时保持旧项目可读，新增可选字段在 `normalizeDocument` 中提供默认值。
- 平面或草图删除必须检查 Extrude/Boolean 依赖；右键删除和 Delete/Backspace 共用同一逻辑。

## 本轮草图维护约定

- 参考匹配必须排除整个当前形状，不允许点或边自参考；其他矩形的中心纳入参考点。
- 正多边形角点复用初始外顶点的半径控制逻辑，不另建顶点数据。
- 尺寸输入 Enter 与 blur 均可写回；退出草图必须清空 face 选择和几何锚点。
- 控制点拖动期间不得同步写回响应式 document；只在 pointerup 写回并同步场景，避免深度 watch 和自动保存拖慢预览。
- 裁边使用 `sketchRestitch.ts` 统一重连：先合并连续开放链，再提取闭环；`sliceBorder` 必须去除重复端点，零长度边不得进入图。平滑圆弧采样属于同一逻辑 border，不能拆成独立草图实体。
- 圆/椭圆 border 求交和区间必须支持采样顶点与跨 0° 区间；不得按线性 0..1 区间处理圆周接缝。
- 重连路径必须维护 `controlPoints`，采样点只参与几何显示，不生成手柄、尺寸输入或参考线。
- 草图右键和坐标球只允许平面 roll，旋转量必须来自指针绕平面原点/坐标球中心的真实夹角，禁止用 3D 轨道或横向像素差近似；三维右键、坐标球及退出草图后必须保持世界 Y 轴向上。
- 封闭面统一由 `sketchFaces.ts` 计算并在每次写回后刷新；不得在多个模块分别用 open 推断视觉封闭区域。面渲染层级必须低于 border/操作点，面点击不得触发形状选择。
- 贝塞尔编辑草稿只使用两个语义端点，65 个渲染采样点仅供显示，禁止把前两个采样点写成端点。
- 已裁剪实体使用 `trimmed` 区分逻辑边编辑：直线端点编辑保持共线并同步更新 `curves`/`analyticCurves`，控制柄固定于 1/3、2/3 位置；控制柄拖动保留非共线曲线且重新选中不消失，两种行为均有 spec；连续曲线端点拖动整体平移；未裁剪实体保持整形状编辑。

## 颜色与填充调整

- `config/colors.ts` 是唯一的三维颜色区：`SKETCH_COLORS` 管草图和操作点，`VIEWPORT_COLORS` 管背景、灯光、实体选中与测量，`GIZMO_COLORS` 管坐标轴，`ENTITY_COLORS` 管新实体默认色。
- 界面颜色也在同一文件：`UI_COLORS` 对应 `var(--model3d-ui-<hex>)`，`UI_NAMED_COLORS` 对应 `var(--model3d-ui-<name>)`，由 `index.ts` 在挂载前注入。调整色值只改 const，不在 Vue/CSS 中新增硬编码颜色。
- 平行线颜色使用 `SKETCH_COLORS.line`；线宽、间距和不透明度在 `config/const.ts` 的 `SKETCH_STYLE.hatchLineWidth / hatchSpacing / hatchOpacity` 调整，单位与草图平面坐标一致。
- 扇形磁吸阈值在 `INTERACTION.sectorQuarterSnapThresholdDeg` 调整；默认在 90° 倍数前后 4° 内吸附。
- 草图参考线及参考对象使用 `SKETCH_COLORS.reference`（参考色）；统一屏幕磁吸距离在 `INTERACTION.sketchGuideSnapPx` 调整，默认 8px。

## 草图高级工具与复合形状

- 对称使用独立二维临时画布，禁止把临时副本或不同 id 的复制实体写入 document；退出不得改动源草图，完成只新增一个含 `parts` 的草图实体。
- 扇区以正上方为 0°、顺时针增加。裁剪必须使用两条无限分界线，轴对称采用相邻扇区镜像，旋转对称采用顺时针旋转；相关边界修改必须更新 `sketchAdvanced.spec.ts`。
- 草图平移/旋转/缩放不得调用三维 `TransformControls`，也不得退出草图。二维手柄与输入直接修改语义点或 `parts`，支持工具优先和形状优先两种选择顺序。
- `parts` 是同一草图实体的多个独立轮廓，border、面、显示、拉伸和选择逻辑必须保持实体级聚合；不得退化为多个临时 Items。
