# 车削与批量拉伸

## 车削（Revolve）

- 交互以 Shapr3D Revolve 为准：先选择**封闭草图区域或一个明确的平面面片**，再启动“车削”。整个 Body 不再提供入口，也不自动猜测最大平面；普通 Transform 的“旋转”继续用于对象变换。
- 启动后固定当前截面，必须再选择一条**与截面共面的旋转轴**。可直接点击草图直线、实体线性边，或从操作条选择可用的世界 X/Y/Z 网格轴；非共面轴会提示，未选轴时不生成预览且不能完成。
- Angle 默认 360°，截面随角度绕轴旋转并扫掠形成实体；小于 360° 生成局部实体。Elevation（界面“轴向位移”）默认为 0，非零时形成螺旋，角度可超过 360°。
- 预览和完成使用同一份截面与轴，完成生成独立实体并写入一步撤销；草图来源隐藏，Body 平面来源保留，取消不修改 document。
- 外轮廓与孔在进入内核前统一绕向；任意轴映射到截面局部坐标，整周与负侧部分扫掠分别处理，禁止用默认平面或任意原点轴代替用户选择。

## 多形状粗箭头批量拉伸

- 3D 模式选择多个封闭草图后，每个轮廓都显示自己的粗箭头和带符号距离输入。
- 拖动或输入任意一个箭头都会进入同一批量拉伸事务，所有选中封闭轮廓共享深度、方向、侧面和拔模参数。
- 批量拉伸继续沿用已有组合实体逻辑，不为每个箭头生成重复历史。开放轮廓的封闭区域检测保持单箭头行为。

## 选择提示

- 3D 提示统一显示 Command/Ctrl + 拖动框选多选；框选与 Command/Ctrl + 单击加选是不同操作。
- 车削激活时，提示区明确引导用户先点击直线/线性边作为轴，或选择网格轴。
