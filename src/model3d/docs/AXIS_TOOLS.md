# 绕轴旋转、车削与批量拉伸

## 绕轴旋转

- 选中一个或多个实体 Body、草图或形状后，高级工具区显示“绕轴”。入口与普通 Transform 旋转分离。
- 操作条提供全局 X/Y/Z 轴、角度和可选轴向偏移。旋转围绕世界原点轴，偏移沿同一轴叠加。
- 角度和偏移只更新视口预览，点击完成才一次性修改所选元素的 position/rotation/scale 并写入一步撤销；取消不写 document。

## 车削

- 单个封闭草图被选中时，高级工具区显示“车削”。草图必须位于显式平面，支持已有语义曲线和复合封闭轮廓。
- 操作条提供草图内 X/Y 轴和 -360° 到 360° 的角度。正角度与负角度控制旋转方向，负侧轮廓自动镜像处理。
- 轮廓不得跨过旋转轴，否则操作失败并保留原草图，避免几何内核静默裁掉负侧区域。
- `engine/modeling/Revolve.ts` 使用 Manifold CrossSection.revolve 生成闭合实体，再映射回草图平面。完成后生成独立烘焙实体并隐藏原草图。

## 多形状粗箭头批量拉伸

- 3D 模式选择多个封闭草图后，每个轮廓都显示自己的粗箭头和带符号距离输入。
- 拖动或输入任意一个箭头都会进入同一批量拉伸事务，所有选中封闭轮廓共享深度、方向、侧面和拔模参数。
- 批量拉伸继续沿用已有组合实体逻辑，不为每个箭头生成重复历史。开放轮廓的封闭区域检测保持单箭头行为。

## 选择提示

- 3D 提示统一显示 Command/Ctrl + 拖动框选多选；框选与 Command/Ctrl + 单击加选是不同操作。
- 绕轴和车削激活时，提示区显示对应轴向、预览和完成说明。
