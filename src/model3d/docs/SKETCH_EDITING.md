# model3d 草图编辑规则

本文是草图编辑的独立维护文档，记录当前交互契约、几何规则和已知限制。修改草图行为时必须同步更新本文，并以浏览器回归验证为准。

相关实现：`App.vue`、`Viewport.ts`、`profiles.ts`、`sketchBorders.ts`、`sketchRestitch.ts`、`sketchFaces.ts`、`sketchGuides.ts`、`sketchConstraints.ts`。

## 1. 进入与退出

### 进入

- 从草图工具选择 XZ、XY、YZ 基准面，或在已有构造平面上开始绘制。
- 选中实体平面后，可直接在该面建立草图平面。
- 选中草图拉伸实体后，可进入其原始 Profile 继续编辑。
- 进入后使用当前平面的正交正视图，只显示当前平面及其草图内容。
- 新进入草图时不自动选中该平面的既有形状；只有显式选择轮廓或编辑拉伸 Profile 时才进入对应编辑态。草图状态隐藏底部实体统计。

### 退出与结束

- “退出草图”完成当前有效轮廓并退出；定义点不足时可取消本次绘制。
- 两点 Line、三点 Arc 可作为独立开放轮廓保存；三点以上 Polygon 显式完成时才封闭。
- “线条 / 曲线”工具使用 `polygon` 开放轮廓；其两点拖拽与独立 `line` 都在 pointerup 复用两次点击的第二点写回入口，禁止只保留预览而不创建实体。右键结束只清除编辑态，不得删除已完成的 Line。
- 完成一个形状或右键结束当前操作后，自动切回“选择”工具。
- 退出草图清空 face 选择、实体树选择和几何锚点；完成草图后仅按既有流程选择新轮廓。
- 相机退出时恢复三维视角，三维操作保持世界 Y 轴向上。

## 2. 选择与取消选择

### 面、形状和逻辑边

- 面 hover 只改变对应封闭区域的 active 填充色；点击面不选择形状。面层级始终低于 border 和操作点，不得遮挡拾取。
- 所有形状的 border 都有独立 hover 高亮，使用较低不透明度的 hover 色；选中反馈继续保持不透明 active 色。
- Alt/Option 的删除预览由键盘事件驱动，先 hover 再按键也必须立即显示红色区间和删除 cursor，不依赖额外 pointermove；松开后恢复普通 hover。
- 未裁剪形状的 border：点击选择整个形状，保持该形状原有的中心、半径、扇形和顶点操作逻辑。
- 已裁剪形状的 border：点击进入独立逻辑边编辑，不再按完整形状处理。实体以 `trimmed` 标记区分。
- 裁剪直线：只显示两个端点和长度；端点可拖动，直线及共线贝塞尔控制点同步保持共线。
- 连续曲线：按切线连续性组成一条逻辑曲线，只显示首尾操作点；拖动任一端时整条曲线平移，不改变曲率。
- 选择点与选择边互斥，不保留旧选择对应的约束状态。

### 右键与 Esc

- 右键单击取消当前路径或选择，并切回“选择”工具；右键拖拽只旋转视图，不触发取消。
- Esc 取消当前路径或选择，不删除已实时保存的有效独立 Line/Arc。
- 切换绘制工具会清空当前编辑态，但不删除其他已保存草图。

### 多选与选择类型

- 选择状态分为 `selectedShapes`、`selectedEdges`、`selectedPoints`，同一类型可多选且不限数量。
- 普通点击 border 选择逻辑边，Ctrl/Command 追加或取消选择；双击未裁剪 border 才进入整形状编辑。未选中的 border 保持正常不透明渲染。
- 逻辑边编辑只隐藏正在编辑的 border，不得隐藏同实体的其他 border；退出编辑时恢复全部 border。
- 多边约束以第一条选中边为参考，参考边使用高饱和 `SKETCH_COLORS.referenceActive`，其他选中边继续使用不透明 active 色。
- 提示区包含“双击 border 选择整个形状”。
- Ctrl/Command 再次点击已选元素可取消该元素；实体树中的形状也支持累加选择。
- 点、边、形状不混选，后选择的类型替换先选择的类型。例如选点后再选边会清空点选择，选边后再选形状会清空边选择。
- 选中元素使用不透明 `SKETCH_COLORS.active`；普通 hover 使用同色但更低不透明度，面 hover 继续使用独立半透明 active 填充。
- 选中控制点保持普通尺寸，使用不透明 active 色，不再额外放大。
- 多个控制点支持同位移批量拖动，固定点不参与批量移动；直线及共线贝塞尔控制点同步保持共线。
- 控制点拖拽需超过 `INTERACTION.sketchDragThresholdPx`（默认 4px）才启动，未超过时只执行点击选择，不写历史或修改几何。

## 3. 参考线与磁吸

- 仅使用其他形状的参考点和真实直线，整个当前形状必须排除，禁止自参考。
- 参考点包括其他形状的语义控制点、矩形对角中心、平面原点，以及世界原点在当前平面上的投影。
- 单点操作生成同轴水平、垂直参考线；形成 Line 边时，额外生成所有真实直线的平行、垂直参考线。
- 曲线细分点、圆弧内部采样和重连产生的非控制点不得作为参考点或伪直线。
- 水平、垂直方向分别保留进入阈值的最近匹配；两个方向同时命中时吸附到参考线交点，并同时显示两条参考线及对应参考对象。只有一个方向命中时保持最近单条匹配。阈值由 `INTERACTION.sketchGuideSnapPx` 配置，默认 8px，并按当前相机换算成平面距离。
- 约束区“关联检查”下提供磁吸开关，默认开启；关闭后仍计算并显示参考线及参考对象高亮，但绘制和拖动坐标不吸附，直接跟随指针。
- 参考线只在鼠标按下后的绘制或拖动过程中显示；普通悬停不计算、不显示参考线，pointerup 后立即清空。
- 普通参考对象使用 `SKETCH_COLORS.reference` 绿色虚线及高亮；原点使用普通 guide 色，不显示绿色参考点。
- 无匹配、拖离阈值、pointerup、退出草图或开始视图操作时，立即清空参考叠加层并恢复原色。
- 扇形角度拖动不使用 Cartesian 参考线，继续使用角度和 90° 磁吸。

## 4. Line、Arc 与形状操作

### Line / Arc

- 第 n 个点只连接 n-1，开放路径不补最后一个点到第一个点的边。
- 两点 Line、三点 Arc 可独立存在，不要求形成封闭面。
- 直线端点移动后仍为直线，原本共线的贝塞尔控制点移动到新直线的 1/3、2/3 位置。
- 双击贝塞尔控制点，将该控制点恢复到所在直线上；已弯曲的线段不会因普通端点拖动自动拉直。

### 圆与椭圆

- 圆使用圆心和圆周点；椭圆使用两个带方向的正交半径向量。
- 椭圆扇形角、裁边和扇形点统一使用局部参数角，不能使用平面旋转角替代。
- 扇形点吸附整数角度，90° 倍数附近增强磁吸；双击恢复完整圆/椭圆。
- 半径拖动期间只更新预览，document 写回和完整场景同步在 pointerup 一次完成。

### 矩形与正多边形

- 矩形保留轴对齐角点逻辑，对角中心同时作为中心操作点和其他形状的参考点。
- 正多边形每个角都显示操作点，拖动任一角与拖动初始外顶点相同，更新同一个半径和旋转方向。

### 尺寸输入与单位

- 项目数值视为无单位，切换 mm/cm/m 不修改数值，只改变展示和导出语义。
- 长度/角度输入使用整数 step；小数值先按操作方向取整，再步进。
- 支持按钮、滚轮、方向键、blur 和 Enter 写回；Enter 必须立即生效。
- 非 hover/focus 输入框为 50% 透明度并平滑过渡。

## 5. 交叉边、裁剪与封闭面

### 交叉边裁剪

- Alt/Option + hover border 显示待删除的交点区间，点击只删除该区间；无交点时删除完整逻辑边。
- 交点包含普通边-边相交、T 型端点相交和恰好落在采样顶点上的交点。
- 圆/椭圆交点区间按环处理，允许删除跨过 0°/360° 的弧段，禁止按普通线性区间处理圆周接缝。
- `sliceBorder` 必须去除重复端点，零长度边不得进入重连图。

### 重连与控制点

- `sketchRestitch.ts` 先合并连续开放链，再提取闭环；连续路径属于同一轮廓，不得把每个采样段拆成独立草图实体。
- 平滑圆弧采样属于同一逻辑 border，后续裁切仍按整条曲线处理。
- `controlPoints` 只记录真实交点和拐角。内部采样仅用于显示、求交和填充，不生成手柄、尺寸输入或参考点。
- 贝塞尔使用 de Casteljau 分割；圆/椭圆保留圆心、半径和局部参数角。

### 封闭面

- `sketchFaces.ts` 在全部交点处分割边，通过有向 half-edge 遍历有界区域；负面积外环不生成面。
- 同一连接节点的端点必须先统一为规范坐标，再执行 half-edge 遍历，避免解析弧端点与采样交点之间的微小缝隙形成伪面或尖刺。
- 每次场景同步和逻辑边写回后重新计算，不得仅凭实体的 `open` 推断视觉封闭区域。
- 多个封闭区域独立生成填充，hover 时只 active 对应区域。
- border 使用 4px 屏幕线宽；操作点显示尺寸为原规格的 60%，尺寸常量集中在 `SKETCH_STYLE`。
- borderTargets 必须按实体去重，禁止模型层与当前编辑层的重复 border 竞争拾取；hover border 时不得同时触发 hover 面。
- 面内平行线使用平面 UV，不跟随视角，不透明度为 50%。

## 6. 约束

- 水平/垂直、平行、正交、等长只处理真实直线，曲线和采样弧段不参与。
- 平行、正交、等长以第一条选中边为参考；需要多边参与的功能依赖完整 Ctrl/Command 多选支持。
- 方向约束按各自轮廓分组求解；平行、正交、等长支持跨实体多选，第一条选中边作为全局参考，其他实体通过临时共享参考求解。
- 所有选中实体的结果先验证再一次性写回，参考边保持不变，任一边求解失败则不修改任何实体。
- 固定可作用于单点或整条边，固定边等于固定其全部端点。
- 固定长度可作用于单条或多条选中直线，每条边独立记录点击时的长度，不引用其他边；拖动其端点时只能沿另一端点为圆心的圆周运动，角点同时受两条固定长度边限制时取圆周交点。
- 固定点、固定边和约束边显示锁标记：点标记位于右上方，边标记位于长度输入左侧；点击标记等价于选择对应元素。长度输入宽度缩减约 20%。
- `edgeConstraints` 保存方向、平行、正交、等长和固定长度关系。拖动或尺寸写回后必须重新执行约束，不能只在点击约束按钮时满足一次。
- 约束执行从变更元素沿参考和依赖关系传播；每次执行使用当次 visited cache 去重。约束面板提供 10–100 的检查上限滑杆，默认 20，并以 `lab:model3d:sketch:constraintLimit` 保存上次设置，超出时停止并通过 message 提示。
- 约束传播按优先级尝试候选方案：当前操作点不变、关联的另一个端点不变、所在形状其余顶点不变，最后选择改动顶点数最少的结果；贝塞尔控制点不计入数量。高优先级方案可通过反向调整参考元素满足，失败后才降级，不直接中止。
- 逻辑边编辑时，“关联的另一个端点”仅指当前 border 的另一端，不得把当前点相邻的其他 border 端点一并固定，否则会使矩形等边的高优先级候选失效并造成连续拖动时边长漂移。
- 链中固定点、固定长度或其他规则在所有候选方案下仍无法满足时，恢复本次操作前的全部几何并提示，不保留部分修改或超限传播结果。
- 每条边可保存多个规则实例，每条规则包含独立 id、类型和参考元素，不能按类型覆盖同边的其他规则。
- 一条规则显示一个锁，边锁右移到长度输入之外；点击锁选中该规则与元素、显示对应约束面板，并以 active/参考色标记当前锁和关联锁。取消只删除当前规则，不影响同边其他规则。
- 锁使用 margin 定位，禁止直接覆盖 Vue 投影容器管理的 transform，避免多规则锁重叠。
- 带贝塞尔控制点的直线编辑必须归一为真实首尾两点；几何约束写回后同步重算共线控制点，禁止把采样点当端点或把直线误判成曲线。
- 拖动等长目标边时优先保留目标边两端并同步参考边；参考边因固定长度等规则无法调整时，保留当前拖动点并调整目标边另一个端点。
- 逻辑边的局部端点索引必须转换为实体顶点索引后再用于选中反馈、固定点和约束锚点，禁止把局部 0/1 直接当成形状顶点 0/1。
- 矩形默认四条边正交，正多边形默认各边等长；形状固有约束与后续用户约束共用同一生命周期。
- 矩形相邻边等长时，等长参考长度必须同时用于两组对边，并在点击约束时立即重建正交四边形；不得只调整一条边或仅检查固定边 index。
- 拖动矩形的任意等长关联边（包括等长参考边）时，先按候选优先级确定该边两端，再以该边为基准只重建另外两个角点；禁止写死以顶边为基准或保留某个角点而移动当前拖动点。
- 删除边、删除点、拆分或删除形状时，必须同时清理自身约束及其他元素对它的引用，禁止遗留失效 reference。
- 点击已有同类约束时取消所选约束，不重复应用；固定锁的开关仍按固定逻辑处理。
- 当前选中边全部具有水平、垂直或方向约束时，对应 H、V、水平/垂直按钮文字使用 active 色并加粗；取消规则或切换选择后同步恢复。
- 含固定点的形状不能通过中心抓手整体移动；只有一个固定端点时，绕该端点调整。
- `sketchConstraints.ts` 对所选边统一求解并验证后一次写回，禁止逐边修改共享顶点。
- 冲突、零长度边、封闭区域退化、非直线输入均拒绝修改，不留下半完成状态。

## 7. 平面旋转与性能

- 草图右键和坐标球只允许绕 N 轴二维 roll，相机位置不变，不进入三维轨道。
- 旋转量来自指针绕平面原点/坐标球中心的真实夹角，方向与当前手势约定一致，不使用横向像素差估算。
- 平面手势与三维坐标球逻辑分离；三维操作保持世界 Y 轴垂直。
- 控制点拖动预览按动画帧合并，拖动期间不执行响应式 document 深写回、完整场景重建或自动保存。

## 8. 本轮补充规则

- 提示组件位于渲染区右侧垂直居中，并监听约束区与自身高度；发生重叠时自动下移到约束区下方。
- 提示组件只使用独立 `hints-panel`，不得复用带 left 定位的 `tool-panel`；提示内容使用 ul/li 列表。
- 提示列表使用实心圆点，并包含 Space 平移画布、Alt/Option 删除边。
- 提示区不使用背景、border 或阴影。
- Line 超过 2 个点时，Shift + 点击连接最后一个点和起点并切回选择工具，cursor 使用 alias；右侧独立提示组件按当前形状显示操作说明。
- 滚轮连续步进只修改当前输入 DOM，停顿约 90ms 后统一写回，禁止滚轮冒泡到画布，避免输入闪动和误触画布缩放。
- 控制点实际拖动期间隐藏长度/角度输入，pointerup 后恢复并重新计算尺寸和参考匹配，确保更新后的点立即进入参考线体系。
- 拖动中的选中反馈点暂时隐藏，避免旧文档坐标留下残影；pointerup 后按新坐标恢复。
- Line/Arc 允许引用同一轮廓的其他点，仅排除正在拖动的点自身，因此 A 移动后 B 可立即使用新 A 做同轴参考；其他形状仍排除整个当前形状。
- 操作点通过 `screenRadius` 按相机和屏幕像素动态缩放，画布 zoom 不改变其显示尺寸。
- 完整圆/椭圆的单边自环也作为封闭面处理，不得因起终点相同而被过滤。
- 粗箭头使用浅色 `SKETCH_COLORS.arrow` 和同色相深色 `arrowOutline` 描边。
